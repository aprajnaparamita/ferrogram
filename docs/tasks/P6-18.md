### Deviations and open issues

- **The `Value` unit hint after an edit.** The edit's own write keeps
  the unit the row's `Value` cell records (own or inherited), but the
  recalc pass that follows writes the cell through
  `Document::write_row_cell`, which re-records the ShapeSheet table's
  unit (ADR 0038's rule) — so a length-ish value loses its `U` display
  hint after the first edit. The value is canonical and correct either
  way. Fixing it needs either `write_row_cell` keeping the recorded
  unit (an ADR 0039 amendment, not mine to make) or the pass skipping
  writes that change nothing (`crates/shapesheet`, P6-17's area).
- **`Prop.<row>` references build no graph edge.**
  `graph::spell_section` does not alias `Prop`/`Character`/`User` the
  way `resolve.rs`'s `canonical_section` does, so a formula spelling a
  Shape Data row the Visio way (`Prop.Cost*2`) evaluates but gets no
  dependency edge and is not revisited after an edit — review F2's
  twin name splitters, `crates/shapesheet` (P6-17's area). The recalc
  test uses the model spelling `Property.Cost`; `Prop.Cost` needs the
  one shared helper F2 asks for.
- **Out-of-lane files (the regenerated command list).** The
  acceptance criteria's "regenerate the command list" needed one row
  in `xtask/src/extract/commands.rs` (`OUR_COMMANDS`) and the
  regenerated `ui-spec/commands.yaml` and `docs/parity/controls.md`;
  `crates/ui-spec/tests/committed.rs`'s pinned row count follows the
  generated data (977 → 978, the same forced companion update P5-04
  made). Nothing else outside the task's `Owns` list changed.
- **Editable kinds.** A Shape Data value of number, boolean, colour or
  string kind is editable; a list or error value has no literal
  spelling to type back and stays read-only (one `InvalidArgs`, the
  pane shows it as before). Pinned by
  `every_refused_entry_names_why_and_changes_nothing`.
- `crates/commands/tests/recalc_edit.rs` (P6-17's file) still mentions
  the deleted `Document::scale_geometry` in two comments and one
  assertion message; left for its owner.

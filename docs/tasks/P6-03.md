## Goal

Implement the value type's operations: the unit table (parse, spelling,
family, canonical conversion, the `geom` bridge), the coercion rule of
`about-operators.md` (typed default plus a `Coercion` warning), the
`Value::to_cached`/`from_cached` mapping that closes P2-14, and the
non-finite rule (a non-finite result is `#NUM!`, never a stored `inf`).

## Acceptance criteria

- [ ] Every unit spelling of `about-units-of-measure.md` parses (universal
      spellings and the localized ones listed there), and `spelling()`
      prints the universal one.
- [ ] Canonical conversions are exact where the factor is exact (1 in =
      72 pt, 1 deg = pi/180 rad) and round-trip within 1e-12 for every
      unit (property test).
- [ ] `coerce` implements the documented rule: `5 * "sheep"` is 0 with a
      `Coercion` warning; `"2"` converts to 2; a number to a string and a
      boolean to a number behave as documented.
- [ ] `Value::to_cached` / `from_cached` round-trip for every value kind
      (property test), and a `Bool`/`Str` with a unit drops the unit on
      write (the P2-14 fix, with a test that reads it back).
- [ ] A non-finite magnitude maps to `#NUM!` on both directions.
- [ ] Area spellings (`SQ IN`, `HA`, `ACRES`) return
      `Error::Syntax{ kind: InvalidUnit }` from `parse_unit`'s caller path
      and are documented as out of scope.
- [ ] Hand-off gate green in the worktree (AGENTS.md section 7: `--quick`
      plus **coverage** and **fuzz** (the shapesheet fuzz target exists
      after P6-02; run it if your change touches the public API), and
      **wasm** if you touch any `Cargo.toml`).

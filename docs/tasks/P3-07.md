## Goal

Write a standalone, deterministic SVG document for any scene.

## Interfaces

Implements (signatures fixed by P3-01):

```rust
pub fn render_svg(scene: &Scene, options: &SvgOptions) -> Result<String, Error>;
```

May add private helpers in `svg.rs` (element writing, number formatting,
XML escaping). The subset of SVG is fixed by ADR 0025: `svg`, `g`,
`path`, `defs`, `linearGradient`, `radialGradient`, `pattern`,
`clipPath`. Text is glyph outlines from `text::Font::outline`, never
`<text>`. Numbers use fixed 6-decimal formatting; attributes are written
in a fixed order; the `viewBox` is in scaled pixels.

Shared file: `crates/render/Cargo.toml` is owned by P3-05. If a test needs
`quick-xml` or `insta` as a dev-dependency, add exactly that line, and say
so in the Result so the master can merge.

## Acceptance criteria

- [ ] `render_svg` implemented for every scene type: paths, fills (solid,
      gradients, patterns), strokes (dashes, caps, joins, line ends),
      shadows, clips, groups with transforms and text outlines.
- [ ] Determinism: rendering the same scene twice is byte-identical;
      a test pins the exact output of a small scene (hand-written expected
      string or an `insta` snapshot).
- [ ] XML safety: text content and attribute values are escaped; output
      parses as XML (a test parses it with `quick-xml`, already in the
      workspace).
- [ ] Unit tests cover each element kind with synthetic scenes; no golden
      dependency on P3-10's harness.
- [ ] `cargo xtask gate` green.

## Note from the master

Group A changed two things the stubs did not show. First, `ferrogram_text::layout`
bakes the text block rotation into glyph positions (ADR 0024 amendment), so
rotate each glyph outline by the block rotation when you draw it; do not
rotate the whole text block again. Second, `ferrogram_render::styles`
(P3-08) documents unit-box conventions for line ends and tile-box
conventions for fill patterns; P3-05 applies them when building the scene,
so the backend draws the scene's paths and paints as given.

## Goal

Implement `DocumentResolver`: resolve every reference form of ADR 0054
through the rungs of ADR 0013, evaluate an inherited formula in the
target sheet's context, prefer the local `Inh` snapshot for values, and
turn a missing reference into `#REF!` with one warning. Close the P3-15
"master-sized geometry on resized instances" rendering gap by the
`CellReader` policy change in `crates/model/src/values.rs`.

## Acceptance criteria

- [ ] A test per row of the ADR 0054 reference-form table, over a small
      in-memory document (including `Prop.Cost` vs `Char.Size` vs
      `Scratch.A5` vs `Geometry1.X2`, quoted names and sheet paths).
- [ ] A master's formula evaluated for an instance reads the **instance's**
      `Width`/`Height` (the resize-recompute foundation; test it directly).

      `Master(..)` as the source (the ADR 0054 amendment, pinned).
- [ ] A missing cell, row or sheet produces `#REF!` plus exactly one
      `MissingReference` warning (no document failure).
- [ ] Name lookup is case-insensitive; a case-only difference resolves.
- [ ] `CellReader` in `crates/model` prefers the local snapshot and no
      longer warns on `Inh` snapshots (model tests, existing tests still
      green).

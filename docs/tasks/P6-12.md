## Result

Report: [`docs/reviews/phase-6-review.md`](../reviews/phase-6-review.md).

**Verdict: approve with fixes — 0 blocker, 2 major, 15 minor.**

- **F1 (major)**: a `SETF` inside a *referenced* cell's formula writes
  through `DocumentResolver::set_cell` during another cell's evaluation,
  bypassing `Evaluation::writes`, `apply_write` and the `SnapshotEngine`
  snapshot — so the write survives undo and violates ADR 0056's one
  write path. Reproducing path in the report; it also reaches the
  cross-check harness (a counted `SETF` mutates the document under test).
- **F2 (major)**: `graph::resolve_ref_address`'s `is_column` and the
  resolver's `column_known` are two different column-versus-named-row
  rules (the graph misses the ShapeSheet table and the master rungs), so
  a formula can lose its dependency edge and keep a stale value after an
  edit. Reproducing path in the report; fix is one shared name rule in
  `shapesheet`.

Master-note rulings (all in the report): `Expr` gets a hand-written
`PartialEq` that ignores spans (no ADR amendment); the omitted-argument
parse error stands and gets recorded in ADR 0051; P6-10's cached-value
reads are safe during recalc (dependencies-first order plus immediate
writes) with F2 as the caveat; P6-10's boolean bridge and rule-3
hard-default reading both stand and need **one ADR 0059 amendment** (the
hard-default skip should also stop being labelled `missing-reference`);
`testfile5.vsdx` for the exit test accepted; P6-11's two open issues
confirmed at their rank (F8 minor status text, F9 minor hardening, no
re-rank).

Gate: `cargo xtask gate --quick` **green** in the worktree at hand-off
(codegen, parity, fmt, clippy, test, doc, deny, layers; run twice, before
and after the report landed). No code changed in this task, so no slow
steps (wasm, fuzz, coverage) are triggered.

## Master notes

- P6-02: `Expr` derives `PartialEq`, so equality includes spans, while
  ADR 0051 says spans are not part of equality (tests strip spans first).
  Rule on it: a hand-written `PartialEq`, or an ADR amendment.
- P6-02: omitted call arguments (`FORMATEX(a,b,,,c)`, 18 of 994 corpus
  formulas) are a parse error by decision. Check that the decision holds.

- P6-10 changed the resolver: a read prefers a referenced cell's cached
  value instead of evaluating its formula again (2 889 disagreements in
  the first cross-check run). Check this is safe during recalc: values

- P6-10 applied two comparison rules that ADR 0059 does not spell out:
  the boolean spelling bridge, and rule 3 read as excluding hard

## Goal

Implement the full grammar of ADR 0051: numbers with unit suffixes and
mixed fractions, the implicit `number[unit, flag]` form, strings with the
doubled-quote escape, booleans, every operator with Visio's precedence
(including the `_GT_` family), function calls and every reference form
kept as written. `print` emits source that reparses to an equal tree.
Everything is bounded (length, tokens, nesting) and never panics.

### What changed

- `src/lexer.rs`: `tokenize` with the bounded scanning of ADR 0051.
  Numbers fold a mixed fraction (`5 1/2` is 5.5) and only read `e` as an
  exponent when a digit follows (`2ed` is 2 with the `ed` unit). Strings
  fold `""`; a quoted name keeps its text as written (doubled quotes
  included) in an `Ident` token. A quote directly after a number is that
  number's unit suffix (`5'`, `5"`, `5°`). Limits: `MAX_SOURCE_LEN`
  65 536 bytes and `MAX_TOKENS` 4 096 (the end marker is not counted).
- `src/parser.rs`: `parse` / `parse_formula`, recursive descent with the
  precedence of `about-operators.md` (unary, `^` right-associative,
  `* /`, `+ -`, `&`, the ordering comparisons, then the equality ones).
  Every reference form of the ADR 0054 table parses with its parts kept
  as written (`CellRef`); calls need their parentheses and take
  comma-separated arguments; the implicit `number[unit, flag]` form
  keeps the unit and the flag. `MAX_NESTING` 32 bounds `()`/`[]`
  groups, unary chains and the `^` recursion, checked before recursion
  grows.
- `src/printer.rs`: `print` emits source that parses back to an equal

  recurse; the printer's depth mirrors the parser's nesting.

### Deviations and resolved ambiguities (for review)

1. **`%` is the operator, not a suffix.** `about-operators.md` lists
   `%` as the unary percentage with `37%` = `.37` as its own example,
   while `about-units-of-measure.md` lists `%` as a unit spelling. The
   two readings collide in `37%`; the operator wins (also what
   `UnaryOp::Percent`'s and `ExprKind::Unary`'s stub docs describe), and
   the `%` unit spelling is written only in the implicit form `5 [%]`,
   where the literal keeps it. `%` parses before or after its operand.
2. **Mixed fraction before the unit.** ADR 0051's EBNF has
   `number = ... [unit] [mixed]`; the implementation reads
   `5 1/2 in` (the mixed fraction of `about-units-of-measure.md`
   directly after the magnitude). The EBNF order would read `5 in 1/2`.
3. **What counts as nesting.** `MAX_NESTING` covers `()`/`[]` groups,
   unary chains and the `^` recursion. A flat chain (`a + b + c + ...`)
   is not nesting: the parser folds it iteratively and the printer walks
   its left spine iteratively. Nesting is therefore bounded everywhere a
   tree can grow deep, without a small ceiling on formula length.
4. **Compound units glue.** `unit = ident` cannot spell `FEET/INCH`;
   the parser takes `ident ("/" ident)*` as one unit when the parts are
   written next to each other (`3FEET/INCH`), which keeps the ADR 0052
   spellings printable. Multi-dimensional spellings (`SQ. IN.`, `CM^2`)
   stay unparseable: `Unit` (P6-03) has no such units either.
5. **A call can be a reference part.** The corpus writes
   `LISTSHEETREF()!User.Direction` and `Sheet.30!SheetRef()`; such a
   part keeps the call's own text in `CellRef`, and what it means is a
   resolution rule (ADR 0054) that will fail to `#REF!` with a warning.
   On its own the same text is a call, so a bare reference whose only
   name part is a call has no spelling; `print` reports it rather than
   emitting a call.
6. **Omitted arguments are rejected.** `FORMATEX(a,b,,,c)` is a spanned
   `UnexpectedToken`: ADR 0051's `call` rule has no omission form and
   the AST has no placeholder to keep one in. This is the only corpus
   shape that does not parse: 18 of the 994 unique corpus formulas (all
   `FORMATEX`, an unknown function whose cached value the engine keeps
   under ADR 0053 either way). If P6-06 wants those cells in the
   dependency graph, the follow-up is a missing-argument node (the
   Interfaces section allows a new enum variant; it would land on
   P6-04's exhaustive matches).
7. **The alternative operators need their spaces.** `_GT_` and family
   are matched as standalone identifiers: `5 _GT_ 2` works and
   `5_GT_2` reads as 5 with the unit `_GT_2`. Splitting identifiers at
   the spelling would break names that contain `_LT_`; no corpus formula
   uses the alternative spellings at all.
8. **`print` validates.** A negative or non-finite magnitude is
   `InvalidNumber` (the grammar has no signed literal: `-5` is
   `Unary(Minus, 5)`), an unwritable unit or flag is `InvalidUnit`, and
   a name that is not one piece as written (`Prop.Cost` as a single name
   part, `My Sheet` as one sheet segment) is `InvalidReference`.
   Round-trip identity holds for every tree `parse` produces; the
   property test and the reference table pin it.

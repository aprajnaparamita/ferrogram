### Deviations

1. **`crates/model/src/mutate.rs` is not a test file** (new
   `Document::write_section_cell`, ~40 lines). The section-level write
   needs the model's unit spelling and mutation rules; the alternative
   (field writes from `shapesheet`) would bypass ADR 0039. The narrowest
   layer that can do it correctly is the mutation API, so it landed
   there with two model tests (`crates/model/tests/mutate.rs`). This is
   the one product change outside the master note's named files.
2. **`corpus/vsdx/recursion-cycle.vsdx` is not a formula cycle.** ADR
   0060 names it for the cycle test; P6-06's Result already recorded
   that the file holds no formulas (its cycle is in the package
   relationships). The corpus test pins that a pass over it changes
   nothing, and the formula-cycle rule is pinned on hand-built cycles
   (`a_formula_cycle_keeps_the_cached_values`,
   `a_cyclic_setf_is_cut_without_a_panic`). The ADR stays as written;
   the report records the substitution.
3. **P6-15's rule is in the pass** (the master note) as one engine-level
   test beside its own six lookup tests:
   `a_style_formula_reaches_the_instance_through_the_masters_style_link`.

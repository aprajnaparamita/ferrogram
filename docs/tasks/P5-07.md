## Goal

Edit shape text in place: open an editor over the shape's text block,
commit as one run, undoable, with the `Text` shortcut scope active while
editing.

## Interfaces

Implement `TextEditor::{begin, finish, original_text}` and `tools/text::handle`
(signatures fixed by P5-01), and `builtins/text.rs` `TABLE` with:

- `text.begin` — open the editor on the selection's anchor shape;
- `text.commit` / `text.cancel` — end the edit (commit writes, cancel
  discards);
- `shape.set.text` — arg `text` (`ArgValue::Text`); writes one run
  (ADR 0044 rule) through `Document::set_shape_text`; one undoable edit
  whose revert restores the old `TextContent` verbatim.

The editor renders in `crates/ui` (egui `TextEdit` in a floating area at
the shape's text-block rect from the scene); the `Text` shortcut scope is
active while `TextEditor::is_active()` (coordinate with P5-05's
`ActiveScopes` wiring; the scope hook reads your editor state).

## Acceptance criteria

- [ ] Double-click with the pointer tool opens the editor on the clicked
      shape; the `Text` tool creates a text box (`insert.drawing.text_box`,
      P5-06) and opens it; `text.begin` works headlessly.
- [ ] Commit writes the text as one run (markers collapse to `IX` 0, ADR
      0044) and is one undo step; cancel discards; the shortcut scope is
      `Text` while editing (a `egui_kittest` test typing into a shape and
      asserting the model's `TextContent`).
- [ ] Multi-run text collapses to the first run and the Result documents
      the observed behaviour (ADR 0044 limit).
- [ ] `crates/commands/tests/text.rs` runs `shape.set.text` through the
      registry and checks undo/redo.
- [ ] No `unwrap`/`expect`/`panic!` in non-test code; editing a shape
      with no text sheet or a stale id is an error, never a crash.
- [ ] Hand-off gate green in the worktree (AGENTS.md section 7:
      `cargo xtask gate --quick`; add **wasm**/**fuzz** only if you touch
      a `Cargo.toml` or the public API of `ui`, `render` or `vsdx`).

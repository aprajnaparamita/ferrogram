# 0015: ShapeSheet codegen — `cargo xtask codegen`

- Status: accepted
- Date: 2026-10-13
- Task: P2-01

## Context

ADR 0008 promised a Phase 2 code-generation step: `ui-spec/shapesheet.toml`
(47 sections, 420 cells, 51 rows, 4 enumerations, generated by P1-04) is the
source of truth, and a committed generated Rust file lets `crates/model`
translate cell names to `.vsdx` element names and consult default units and
values. The P1-02 review fixed the rules: no `build.rs`, deterministic
output, `--check` mode, gate-enforced freshness.

## Decision

### The command

```
cargo xtask codegen            # regenerate committed outputs
cargo xtask codegen --check    # fail if any committed output is stale
```

`cargo xtask codegen` is a new xtask dispatcher (sibling of `extract`), owned
by task P2-02:

- **Input:** `ui-spec/shapesheet.toml` (committed).
- **Output:** `crates/model/src/generated/shapesheet.rs` (committed), plus
  `crates/model/src/generated/mod.rs` if the module set grows.
- **Header** (first line of every generated file):
  `// GENERATED by `cargo xtask codegen` from `ui-spec/shapesheet.toml` — do not edit.`
- **Determinism:** the same TOML always yields byte-identical output (sorted
  iteration, no timestamps, no absolute paths).
- `--check` regenerates into a scratch directory and compares byte-for-byte,
  the same contract as `cargo xtask extract --check` (ADR 0009). A stale file
  is an error naming the file and the command to run.

### What the generated code contains

```rust
pub mod generated {
    /// One section of the ShapeSheet table.
    pub struct SectionDef {
        pub name: &'static str,
        pub section_index: i32,
        pub kind: &'static str,          // "object" | "collection"
        pub default_unit: &'static str,
    }
    /// One row definition (the global rows table).
    pub struct RowDef { pub name: &'static str, pub row_index: i32, pub section: &'static str }
    /// One cell definition.
    pub struct CellDef {
        pub name: &'static str,
        pub section: &'static str,
        pub cell_index: i32,
        pub kind: &'static str,          // "Number" | "String" | "Bool" | "Color" | "List"
        pub default_unit: &'static str,
        pub default_value: Option<&'static str>,
    }

    pub static SECTIONS: &[SectionDef] = &[ /* ... */ ];
    pub static ROWS: &[RowDef] = &[ /* ... */ ];
    pub static CELLS: &[CellDef] = &[ /* ... */ ];
    pub static CELL_INDICES: &[(&str, i32)] = &[ /* vis_cell_indices */ ];
    pub static SECTION_INDICES: &[(&str, i32)] = &[ /* vis_section_indices */ ];
    pub static ROW_INDICES: &[(&str, i32)] = &[ /* vis_row_indices */ ];

    /// The definition of one cell of one section, by names, or `None`.
    pub fn cell(section: &str, cell: &str) -> Option<&'static CellDef>;
    /// The definition of one section, or `None`.
    pub fn section(name: &str) -> Option<&'static SectionDef>;
}
```

**Tables, not enums.** 420 cells as an enum would churn on every upstream
change, and unknown cells must be representable anyway (ADR 0012 keeps their
names). The model keys cells by `CellName` strings and uses the tables for
names, indices, types and defaults. If a later task wants typed constants for
the few cells it touches often, it adds `pub const PINX: CellName` items by
hand on top of the table.

### Freshness in the gate

A new gate step `codegen` runs `cargo xtask codegen --check` (added by P2-02
to `xtask/src/gate.rs`; `--quick` does not skip it: it is fast). The step
fails the gate when the committed generated file is stale or missing.

## Consequences

- `crates/model` compiles without `reference/` and without a build script.
- Upstream ShapeSheet changes (a re-run of the P1-04 extractor) need one
  `cargo xtask codegen` and one commit; the gate catches forgetfulness.
- `generated/` inside `crates/model` is owned by P2-02 only; every other task
  treats it as read-only.

## Alternatives considered

- **`build.rs` in `crates/model`.** Rejected by the P1-02 review (M1): build
  scripts must write only to `OUT_DIR`.
- **Runtime TOML parsing / `include_str!`.** Rejected in ADR 0008.
- **A separate `ferrogram-shapesheet-table` crate.** Keeps `model` cleaner,
  but adds a crate for one generated file and one consumer. Rejected; the
  module path `crates/model/src/generated/` is enough.
- **Emit enums (`CellKind::PinX`).** Rejected: 420 variants, upstream churn,
  and unknown cells still need a fallback name. Tables plus `CellName` keys
  cover known and unknown uniformly.
- **Run codegen in `cargo test` and compare.** Rejected: the gate is the one
  enforced place (AGENTS.md section 7); a test would duplicate the check
  invisibly to CI.

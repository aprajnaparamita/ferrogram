## Goal

1. **Gate runner (P4-12 major 5).** Test step selection, the `--quick`
   skip rules, failure aggregation and the summary line without
   running cargo: inject the step runner (a function or trait the
   tests replace). The real gate output must not change.
2. **Parity error arms (P4-12 major 6, minor 9).** A test for every
   failure branch of the parity generator listed in the report,
   including `glob_match`'s bad pattern and `md_escape`'s control
   characters.
3. **Fuzz housekeeping (P4-10).** Add `!corpus/` to
   `crates/ui-spec/fuzz/.gitignore` the same way as the other fuzz
   crates. Add a small seed corpus for the two `crates/ui/fuzz`
   targets (`settings_json`: a valid settings slot, an empty one, a
   truncated one; `shortcuts_map`: a few short byte strings that decode
   to a one-entry and a multi-chord table). Seeds are our own original
   bytes: one `ATTRIBUTION.md` row covers them.

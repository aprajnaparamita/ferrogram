## Goal

Opening a corpus file shows the page on the canvas: the scene renders to
a raw RGBA texture, the view pans and zooms, rulers and grid draw around
it, page tabs switch pages, and the status bar reports the page, zoom and
warnings.

## Interfaces

```rust
// crates/render/src/raster.rs (stub filled in)
pub fn render_raster(scene: &Scene, opts: &RasterOptions) -> Result<RasterImage, Error>;
```

Implementation rule (ADR 0033): `render_raster` and `render_png` share
one rasterizer; `render_png` encodes the raster `render_raster` returns
(no pixel divergence; the PNG goldens cover the canvas pixels). The ADR
0025 caps and errors apply unchanged.

```rust
// crates/ui/src/canvas.rs (stubs filled in)
pub fn show(&mut Ui, &mut DocumentSession, &mut CanvasCache) -> Result<CanvasOutput, UiError>;
pub fn show_rulers(&mut Ui, &DocumentSession) -> Result<(), UiError>;
pub fn show_page_tabs(&mut Ui, &mut DocumentSession) -> Result<Vec<Intent>, UiError>;
pub fn show_status_bar(&mut Ui, &AppCtx) -> Result<(), UiError>;
```

Cache rules (ADR 0033): re-rasterize on document change or page switch;
on zoom change only when the settled zoom moved more than 10% from the
rasterized zoom; panning never re-rasterizes (texture transform). The
texture is uploaded to egui with `Context::load_texture` and dropped via
`TexturesDelta` handling (egui 0.37: apply or clear deltas; never leave
unapplied deltas — it panics on drop).

Interaction: middle-drag or space-drag pans; Ctrl + wheel zooms at the
pointer; the `view.zoom.in`/`view.zoom.out`/`view.zoom.fit` commands
(registered by P4-02) are produced as `Intent`s from the canvas keys and
menu items. Rulers draw ticks at 1/8 inch in `Settings::units`
(conversion at this edge only, AGENTS.md section 6). The grid draws
behind the texture when `ViewState::show_grid`. Page tabs produce
`page.next`/`page.previous` intents and direct `active_page` changes on
click. The status bar shows page name and size, zoom percent, and the
last `AppCtx::warnings` entry.

## Goal

Both layouts render as egui ribbons from the committed YAML, every
placement accounted for, controls without implemented commands disabled
with "Not yet implemented", and the layouts load from embedded YAML so
the wasm build works without a filesystem.

## Interfaces

```rust
pub const SHORTCUTS_YAML: &str = include_str!("../../../ui-spec/shortcuts.yaml");

// crates/ui-spec/src/loader.rs (one addition)
impl Loader {
    /// Loads both layout sets from the embedded YAML (ADR 0031).
    /// Same validation path as `load_all`, minus the schema file read.
    pub fn from_embedded() -> Result<LayoutSets, LoadError>;
}
```

Ribbon behaviour (ADR 0031): walk the layout tree by placement path;
`Ribbon::show` renders the tab strip and the active tab's groups;
galleries/dropdowns/menus are one-button dropdowns; `splitButton` is a
button plus an arrow button; `labelControl`/`control`/`none` are labels.
Every actionable widget produces `Intent { command, invocation:
Invocation::empty(Source::Ribbon) }` when its command is
`CommandStatus::Implemented` and `Enabled::yes`; otherwise it renders
disabled with the tooltip "Not yet implemented" (or the `Enabled`
reason). Repeats inside one container with identical id, label and order
render once (first wins, ADR 0031). The quick access toolbar uses the
same rules from `Layout::quick_access_toolbar`.

Icons: `icons::placeholder` draws our own simple marks (letter or
geometric glyph) sized `SizeVariant`-independent for now; no icon set is
committed (ADR 0030).

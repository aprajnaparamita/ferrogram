### Bugs found (fix commits + regression tests)

1. **`markdown::split_row` lost a trailing-pipe cell after an escaped
   backslash** — `|a\\|` (the cell `a\` with a closing pipe) parsed as
   two cells, because the trailing-pipe rule only looked for a literal
   `\|`. Now the trailing pipe is dropped when it follows an *even*
   number of backslashes. Fix commit `6e04bfe`, regression test
   `extract::markdown::tests::tables_trailing_escaped_backslash`.
   Extracted outputs unchanged (`--check` green).
2. **The out-of-scope `*` glob did not match every string** — it
   compiled to `.*`, whose dot does not match newlines. Now `(?s:.*)`.
   Fix commit `60ab62b`, regression test
   `extract::parity::tests::star_glob_matches_across_newlines`. No id
   contains a newline, so outputs unchanged.

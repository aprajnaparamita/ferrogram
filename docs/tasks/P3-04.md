## Goal

Implement the layout API and the font stack, bundle the two fonts with
their licences, and make missing fonts and glyphs warn instead of fail.

## Interfaces

Implements (signatures fixed by P3-01):

```rust
pub fn layout(block: &Block<'_>, fonts: &FontStack) -> Result<Layout, Error>;

impl Font {
    pub fn from_bytes(bytes: Vec<u8>) -> Result<Font, Error>;
    pub fn outline(&self, glyph: GlyphId) -> Result<larrygram_geom::Path, Error>;
}
```

`Font::outline` returns the glyph outline in **em units** (size 1);
backends scale by `size / 72` inches per point (ADR 0024). `skrifa` parses
and outlines fonts, `harfrust` shapes runs (kerning and default features),
`unicode-linebreak` gives break opportunities; the wrappers stay in
`crates/text/src/font.rs` so the crates can be swapped later.

Also provides (new, documented):

```rust
/// The bundled Carlito faces (for Calibri).
pub static CARLITO: &[FontSource];   // or one const per face; your choice
/// The bundled Selawik faces (for Segoe UI).
pub static SELAWIK: &[FontSource];
/// Builds the default stack: Carlito, then Selawik.
pub fn default_fonts() -> FontStack;
```

Consumers: `larrygram-render` (P3-05 builds `TextNode`s, P3-06/P3-07 draw
glyph outlines).

  2,738,668 B (4 faces + licence), Selawik 225,485 B (5 faces +

  `ATTRIBUTION.md` row per file in the same commit; `docs/sources.md`
  rows 11–12 (renumbered from 9–10 by the master at merge) and `reference/SOURCES.md` sections 11–12 record URLs,
  versions, licences, sha256 and the local raw paths (the raw downloads
  stay in `reference/fonts/`).
- **`font.rs`.** `Font::from_bytes` parses a face with `skrifa`
  (typographic family name, weight, italic, line metrics); `Font::outline`
  returns a `larrygram_geom::Path` in em units, font orientation (y up).
  `FontStack::resolve_styled(family, bold, italic)` selects by family,
  style and weight distance with substitute aliases (Carlito → `Calibri`,
  Selawik → `Segoe UI`, case/space/hyphen-insensitive). `CARLITO`,
  `SELAWIK` `FontSource` statics and `default_fonts()` serve the bundled
  faces (parsed once, cloned out).
- **`layout.rs`.** The full layout: greedy UAX #14 wrapping
  (`unicode-linebreak`), `\n` hard breaks, left/center/right/justify,
  line-spacing multiples, space before/after, first-line and left
  indents, bullets (own glyph run, `BULLET_RUN`), tab stops with the
  0.5-inch overflow rule, vertical alignment, margins and block
  rotation. Shaping is `harfrust` per piece (kerning and default
  features), with nominal `skrifa` advances as fallback when shaping
  fails. Missing fonts and glyphs warn and never fail (ADR 0021);
  non-finite/negative input returns `Error::InvalidBlock`.
- **Tests.** 55 tests in `crates/text` cover every layout feature, both
  warnings, the fallback rules and the error paths. Numeric expectations
  are pinned golden layout numbers (Carlito line metrics 1950/550 per
  2048 em, advances and line widths in inches, e.g. `"hi"` at 12 pt is
  0.125813802 in wide with baseline 0.158691406 in).

### Deviations from the P3-01 interfaces (ADR 0024 amendment records all)

1. **`Warning::MissingGlyph` gains `char: char`.** The fixed
   `glyph: GlyphId` cannot name a character that has no glyph in any
   bundled face; `glyph` records the `.notdef` used instead (always
   `GlyphId(0)`). Consumers print `char`.
2. **`layout` applies `Block::rotation`** to glyph positions (rigid
   rotation about the box centre), instead of the scene builder rotating
   everything. Backends rotate each glyph outline by the same angle
   about its glyph origin; `Line::baseline`/`width` and
   `Layout::width`/`height` stay unrotated.
3. **Bullet placement** is `indent_left + bullet.indent`, not
   `indent_first` (the ADR wording put the bullet on top of the text for
   the common values).
4. **Selawik ships no italics**; the five released weights are bundled
   instead of the ADR's Regular/Bold/Italic/BoldItalic set. An italic
   run asking for `Segoe UI` draws in **Carlito Italic** and warns
   `MissingFont`. A synthetic slant needs an output-API extension
   (`GlyphPos` has no flag), so we did not synthesise one.
5. New public items beyond the ADR sketch (documented):
   `FontSource`, `CARLITO`, `SELAWIK`, `default_fonts()`,
   `Font::{with_alias, aliases, matches_family, weight, bold, italic}`,
   `FontStack::resolve_styled`, `BULLET_RUN`, `Error::InvalidBlock`.
   `FontStack::resolve` keeps its stub semantics.

### Open issues

- Italic `Segoe UI` runs use Carlito Italic, whose metrics differ from
  Segoe UI italic. If Phase 4 needs metric-exact italic Segoe, extend
  the output API for a synthetic slant and reconsider.
- `Warning::MissingGlyph.glyph` is always `GlyphId(0)`; `char` carries
  the information.
- Justify with tab stops on the same line lets the stretched spaces
  shift the tab pen (tabs resolve against the stretched pen). Rare
  combination; revisit if a corpus file exercises it.
- Line spacing is multiples of the font's default line height only;
  Visio's "at least" and "exactly" modes stay out of scope (ADR 0024).
- Underline and strikethrough flags are carried in `Format` but layout
  emits no decoration geometry; the renderer draws them from font
  metrics (P3-06/P3-07).
- A run whose family resolves to no font at all (empty `FontStack`)
  keeps its line structure (hard breaks, empty lines) but emits no
  glyphs; warnings name the missing family.

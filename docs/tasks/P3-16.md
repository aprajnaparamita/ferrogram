## Goal

Fix the review findings. Each fix gets a regression test.

1. **Major 1, silent non-finite substitution.** Reject non-finite numbers
   in `CellReader::number_from` (and `number_from_or`) with one
   `KindMismatch` warning. Remove `Ctx::finite` in `build.rs` or make it a
   no-op that cannot substitute silently. Test: a shape whose `PinX`
   caches `V='inf'` renders at the default and records one warning.
2. **Major 2, text rows by `IX`.** Thread the marker `IX` through as
   `row_ix` for the `CellReader::row_*` family, and delete the
   `ix as usize` fallback in `row_position`. Test: an instance with no
   `Character` section and a master whose rows are `IX` 0 and 5; the run
   marked `IX` 5 reads the master's row 5.
3. **Major 3, pattern tiles.** Add `filled: bool` and
   `tile_stroke_width: f64` to `PatternPaint`, set them from the
   `PatternTemplate` in `build_fill`, and make PNG and SVG both honor them.
   Test: an open tile draws the same marks in both backends.
4. **Major 4, duplicated text fields.** Keep `text::Layout::rotation` and
   `GlyphPos::size`. Remove `TextNode::rotation` and `TextRun::size`, and
   update the placement recipe in `scene.rs`.
5. **Minor 5, one scale cap.** Bound the device extent (page size times
   scale, at most 16384 px per side) in both backends. Add
   `Error::InvalidOptions` for a non-finite, non-positive or over-cap
   scale. Update `a_huge_scale_caps_the_raster_not_the_svg_text` (P3-11)
   and the CLI exit-code tests if the code changes (keep exit 3 or record
   the change in ADR 0026's amendment via an Open issue).
6. **Minor 6.** Amend ADR 0020: a group's own shape is drawn first, as
   the first child of its `Group`, with an identity transform; sub-shapes
   follow in file order.
7. **Minor 7.** Fix the stale sentence at `crates/render/src/scene.rs:27`:
   a node transform maps into the parent group's space; the ancestor chain
   maps to the page.
8. **Minor 9.** Formula-parse degradations in the builder use
   `KindMismatch` (or a new kind if ADR 0021's amendment says so), not
   `ErrorValue`, so the CLI no longer prints them as a cached error.
9. **Minor 10.** `section_rows` counts gradient rows through the same
   master rung as the cell lookup and shares `MAX_DEPTH`; remove the magic
   bound of 8.
10. **Minor 11.** Record one `CellWarning` at build time when a glyph cannot
    be drawn (font index out of range or no outline), or document the skip
    in the placement recipe. Pick one and say which in the Result.
11. **Minor 12.** Make `BuildOptions::new()` and `Default` agree
    (`background: true` for both, unless you find a caller that needs
    otherwise).

Major 8 (silent curve degradation) is P3-18's ADR amendment; do not add
warnings for it here.

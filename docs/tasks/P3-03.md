## Goal

Implement `Curve::to_cubics` for every curve kind of ADR 0022, within the
documented tolerance, with no panics on degenerate input.

## Interfaces

Implements (signatures fixed by P3-01):

```rust
impl Curve {
    /// Cubic Bézier approximation within `tolerance` inches (ADR 0022).
    pub fn to_cubics(&self, tolerance: f64) -> Result<Vec<Cubic>, Error>;
}
```

## Acceptance criteria

- [ ] `to_cubics` implemented for `Arc`, `EllipticalArc`, `Quad`, `Cubic`,
      `Nurbs`, `Spline`, `Polyline`; `Error::NotImplemented` is gone from
      `ferrogram-geom`.
- [ ] Every curve kind has unit tests, including `Arc` with positive,
      negative and zero bow, `EllipticalArc` with and without `angle`/
      `ratio` semantics, and at least one NURBS and one spline with known
      control points.
- [ ] Degenerate input (zero chord, `bow = 0`, `ratio <= 0`, wrong knot or
      weight counts, non-finite values) degrades to the straight chord,
      never panics and never errors the render (ADR 0022).
- [ ] A property test shows the flattened cubics stay within `tolerance`
      of the true curve where it can be evaluated (e.g. an arc against its
      exact circle) and that the conversion never panics on random
      bounded inputs.
- [ ] `cargo xtask gate` green; `ferrogram-geom` keeps its 100.0% ratchet
      (every line covered — this crate is small enough to keep it).

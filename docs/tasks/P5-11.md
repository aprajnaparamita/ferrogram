**Product fixes the tests found** (each with a regression test):

1. `fix(model)` `Document::restore_shapes` returned `Connect` records
   at the end of the list; `DetachedShapes` now keeps their indices.
2. `fix(commands)` a multi-shape z-order undo interleaved the page
   list (`ZOrderEdit` records its own apply-time index).
3. `fix(commands)` group and ungroup undo were not exact inverses
   (snapshots + `reuse_slot` + `place_at`).
4. `fix(commands)` `PagesEdit` restored stale `shapes`/`Connects`
   lists (it now keeps the live lists of surviving pages).
5. `fix(commands)` paste, duplicate and glue-on-drop did not re-route
   (ADR 0045 rule 3, ADR 0046).
6. `fix(commands)` a connector inside a group routed through the wrong
   transform (`write_path` maps through the parent chain).
7. `fix(commands)` the re-route pass hijacked glue-on-drop instances
   as connectors (`is_connector_end`).
8. `fix(ui)` the drag frame was 80-110 ms against the ADR 0042 8 ms
   budget: the snapper and `selection_frame` rebuilt the page scene
   every frame and `snap_move` recomputed moving connection points
   inside the O(n) loop. The same frame measures 0.6-1.6 ms now.

### Deviations

1. **No fuzz target for the ui-spec embedded loader.** The condition
   in the goal ("if it parses untrusted text") is not met:
   `Loader::from_embedded` parses `include_str!` build-time text, and
   hostile YAML through the disk loader is already
   `crates/ui-spec/fuzz`'s `loader_fuzz` (P1-08). The untrusted text
   surfaces in scope (settings slot, shortcut tables) got the two new
   targets instead.
2. **Property tests without proptest in `crates/ui`** (settings
   round-trip): `crates/ui/Cargo.toml` is P4-03's file, so the
   property uses a seeded LCG; `crates/commands` has proptest and
   uses it.
3. The zip 9 `"zip entry name is malformed"` arm is unreachable with
   zip 9.0.4 (`ZipFile::name()` decodes any bytes, UTF-8 else CP437),
   so the tests pin the reachable contract on those inputs instead of
   the arm itself; the report records why.

### Open issues

- ADR 0036 review: the chord that mismatches a half-typed sequence is
  dropped when the mismatch fires the held-back completion (pinned as
  documented behavior in `a_prefix_sequence_defers_and_fires_on_a_mismatch`);
  decide drop vs. retry-as-fresh-start.
- `builtins::with_undo` puts the undo stack back by document index
  after the call; a Phase 5 `Edit` that changes `AppCtx::documents`
  could put it in the wrong session.
- `UndoStack::default()` is capacity 0 (keeps nothing): right for the
  `mem::take` placeholder, a trap for anyone else. Document in ADR
  0028 or make `Default` use `DEFAULT_CAPACITY`.
- `CommandId::intern`'s process-global 4096-id pool is a testing
  hazard (any test binary that interns arbitrary valid ids will hit
  "id pool is full"): a test-only reset hook or a documented cap raise
  would help.
- `crates/ui/Cargo.toml` (P4-03's file): add `proptest` so the ui
  properties follow the workspace convention.
- `crates/ui-spec/fuzz/.gitignore` lacks `!corpus/` (no seed corpus
  there today; align when one lands). The new `crates/ui/fuzz` targets
  have no seed corpus either (a committed seed needs a
  `corpus/PROVENANCE.md` row, which is not this task's file).
- The new fuzz crate adds a one-time cold build (about 4-8 minutes)
  to the gate's `fuzz` step per `CARGO_TARGET_DIR`.
- The committed `shortcuts.yaml` still has no multi-chord sequence;
  real keytip data never exercises the deferred completion (covered by
  tests and the `shortcuts_map` fuzzer only).

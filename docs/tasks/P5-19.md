## Goal

Fix every finding of the Phase 5 review and close the commands and
model coverage gaps the audit named, so that `larrygram-commands` has
real margin over its ratchet.

1. **F1 (major).** `edit.delete` drops any target whose ancestor is also
   a target (one warning line), so a group plus its member deletes once
   with one undo step. Test both selection orders.
2. **F2 (major).** `group_shapes` and `ungroup_shape` compute and check

### Deviations

1. **`master_size` guard made reachable.** The audit says the guard is
   reachable from the public API with a NaN master `Width`; it is not:
   the cached-value policy (ADR 0021) folds a non-finite cached number
   into `0` before `frame_of` sees it. `master_size` now checks the
   master shape's own cached `Width`/`Height` entries first and reports
   `Error::BadCell("non-finite master size")`, so the guard's
   documented intent holds and the fixture test asserts it.
2. **F9 needed one behaviour fix.** The pinning test found that an undo
   of an ungroup selected the **discarded fresh arena slot** (a shape no
   page reaches) instead of the restored group: `regroup_exact` now
   returns the arena id the group ended up at and `UngroupEdit::revert`
   selects it (`183ee71`).
3. **Two model tests changed sides.** `crates/model/tests/mutate.rs`'s
   `group_shapes_reports_a_non_finite_member_pin` and
   `ungroup_reports_a_non_finite_pin_or_angle` pinned the old
   mid-mutation errors (`BadCell("non-finite number")`); they now expect
   the pre-mutation errors and assert the document is unchanged.
4. **`insert_subshape`** got the same validate-first rule as
   `insert_shape` (F11's bug shape, one file).
5. **One pre-existing test** in `builtins/clipboard.rs` used
   `.err().expect(...)`, which clippy 1.95's new `err_expect` lint
   rejects; rewritten with the same `.map(|_| ()).expect_err(...)` as
   the new tests (`d094687`).

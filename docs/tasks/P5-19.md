## Goal

Fix every finding of the Phase 5 review and close the commands and
model coverage gaps the audit named, so that `ferrogram-commands` has
real margin over its ratchet.

1. **F1 (major).** `edit.delete` drops any target whose ancestor is also
   a target (one warning line), so a group plus its member deletes once
   with one undo step. Test both selection orders.
2. **F2 (major).** `group_shapes` and `ungroup_shape` compute and check
   every derived value (`width`, `height`, centre, member deltas) before
   the first mutation, and fail with the document unchanged. Record the
   rule "a failed mutation changes nothing" in an ADR 0039 amendment.
   Test with two shapes at extreme cached pins.
3. **F3 (major).** Move the dispatch-and-push logic of
   `shell::dispatch_one` into `ferrogram_commands` (for example
   `ferrogram_commands::dispatch(registry, ctx, command, invocation)`):
   execute, take `Outcome::edit`, push it with the session the command
   ran against. `shell::dispatch_one` calls it. Replace the copied
   `dispatch` helpers in `crates/commands/tests/*` with the new function.
4. **F4, F5.** Delete `document_pages` and its test; drop the stale
   `#[allow(dead_code)]` attributes.
5. **F6.** One formula spelling for numbers: export the model's
   `literal` rule (or a `CellWrite::number` constructor) and use it in
   `builtins/edit.rs`.
6. **F7.** `write_connector_path` either keeps the connector's extra
   `Geometry` sections or documents the collapse in its doc comment and
   ADR 0045. Choose one and test it.
7. **F8.** Add a `UiError` variant for invalid geometry; `snap.rs` uses
   it instead of `Io`.
8. **F9.** Write down in ADR 0040 that group/ungroup undo selects the
   affected shapes and a page restore clears a stale selection, or make
   the edits restore the prior selection. One test pins the rule.
9. **F10.** Replace the `Vec::contains` visited sets in `next_visio_id`,
   `subtree_ids` and `walk_position` with a set; index taken names once
   per instantiate instead of cloning every `name_u`.
10. **F11.** `insert_shape` validates `children` before adding the shape
    to the arena.
11. **Coverage (P5-13).**
    - One helper for the "connectors were not re-routed" warning (four
      copies today); one failing-route test through paste or arrange.
    - A paste fixture whose `Connect` record names a shape outside the
      copied set (`connector.rs` stale-target arm; P5-11 open item).
    - A drop of a document master with no `Connection` rows
      (`insert.rs` "no connection points to glue"): decide whether it
      warns, then test it.
    - `edit.delete` with glue: the glue warnings and the
      `StructuralEdit::removal` error arm.
    - `master_size` with a non-finite master `Width` (`mutate.rs`).
    - The poisoned id-interner arm in `crates/commands/src/lib.rs`
      becomes `PoisonError::into_inner()` recovery.
    - Delete `lookup::repeated_cell`'s dead `Some(row)` arm (P5-15) and
      the inline test double's never-failing `revert` arm in
      `crates/commands/src/edit.rs`, or give each a test.
    - Fold the three 8.5 x 11 in page-size fallbacks into one exported
      helper only if it stays inside the files you own; otherwise list
      it under Open issues.

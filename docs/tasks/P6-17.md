## Goal

Close every finding below with a fix and a regression test (or, where
the review allows it, a documented rule).

### Major

1. **One write path for `SETF` (review F1).** A `SETF` inside a
   referenced cell's formula, evaluated inline during a read, must not
   write through `DocumentResolver::set_cell`. Record the write and let
   the pass apply it through `Evaluation::writes` and `apply_write`, so
   it gets a `CellUpdate`, dirties its dependents and is inside the undo
   snapshot. A read-only context for nested evaluations is acceptable
   only if the ADR 0056 text then says nested `SETF`s are dropped, with
   a warning. Turn the "F1 reproduces" path into a test, including one
   through `RecalcEdit` showing undo restores the target.
2. **One column-versus-row rule (review F2).** Give `shapesheet` one
   helper that answers "what does this name mean against this section"
   and use it from both `resolve.rs` (`column_known`) and
   `graph.rs` (`is_column`, `resolve_ref_address`). Merge the twin name
   splitters (`split_row_name`/`split_section_name`/`canonical_section`
   against `split_row_suffix`/`split_section_number`/`spell_section`).
   Turn the "F2 reproduces" path into a test: an edit re-evaluates the
   dependent formula.

### Minor (review)

3. F3: one rule for the `SETF` writes of an evaluation that stands back
   (`UnknownFunction`, `Syntax`). Recommended: drop them, so a cell that
   keeps its cached value has no side effects. Record the rule in
   ADR 0056.
4. F4: hand-written `PartialEq` for `Expr` comparing `kind` only; delete
   the span-stripping test helpers (`without_spans`, `strip`).
5. F5: record the omitted-argument decision in ADR 0051 (no empty
   argument production; added when a known function needs one).
6. F7: count nested evaluations against the budget (a counter on the
   resolver), or document in ADR 0056 that the budget bounds pass-level
   evaluations only. Recommended: count them.
7. F8: one `warning_line` text per new kind (`WrongArgumentCount`,
   `SetfRefused`, `Coercion`, `NonFinite`, `Syntax`), with a test each.
8. F13: when `run_pass` fails mid-pass, keep the snapshots already taken
   so undo removes the partial writes.
9. F16: a warning raised in a referenced cell's formula names that cell,
   not the outer one.
10. F17: fix the stranded sentence in `eval.rs`'s module docs; add the
    postfix `%` production and one line on the 15-digit comparison of
    the `_GT_` family to ADR 0051.

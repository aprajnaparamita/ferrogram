## Goal

1. **Writer insert direction (major).** Round-trip cases that edit a
   *read* document so the patcher must add a child the source part lacks:
   insert a shape onto a read page, write a cell the read shape does not
   define, add a row and a section, add a `Connect`, add a style, add a
   page and a master. Each saves, reopens and checks ADR 0048 equality
   (reuse the comparison rules of `apps/ferrogram/tests/flowchart.rs`
   by copying them; tests cannot import from another test crate). This
   reaches the `sync_children` build closures and `page_rank` /
   `shapes_rank` in `crates/vsdx/src/write/patch.rs`.
2. **Patch attribute arms (minor).** One fixture with a spelled-out
   boolean (`TRUE`) and one with unparseable text, through `sync_uint`
   and `bool_matches`.
3. **UI tool state (major).**
   - The page-tab context menu: Rename, Delete, Move Left/Right, plus
     tab clicks and `page.previous`/`page.next`, through the real
     `Shell` (`crates/ui/src/canvas.rs` page-tab code).
   - The pointer's entered-group hit walk (`tools/pointer.rs`): enter a
     nested group, click a member, click outside, and check the
     selection never gets stuck inside the group.
   - The connector tool with the "Connector" master missing: the error
     reaches the status bar as one line and nothing is inserted.
   - Click outside the text editor: whether it commits (P5-07 black-box
     check); pin today's behavior.
4. **Hit-test fallback (minor).** One `render` test with a geometry row
   kind the hit tester does not map (`render/src/hit.rs` catch-all).
5. **Margin.** `ferrogram-render` is at 98.39% against a 98.4 ratchet;
   aim for **98.5%** or higher. Raise `ferrogram-ui` and
   `ferrogram-vsdx` where the tests above allow.

## Goal

Implement the full grammar of ADR 0051: numbers with unit suffixes and
mixed fractions, the implicit `number[unit, flag]` form, strings with the
doubled-quote escape, booleans, every operator with Visio's precedence
(including the `_GT_` family), function calls and every reference form
kept as written. `print` emits source that reparses to an equal tree.
Everything is bounded (length, tokens, nesting) and never panics.

      malformed inputs). Fuzzing never panics on the seed corpus.
- [ ] Unknown function names and unknown reference forms parse (they are
      identifiers); a malformed one is a spanned syntax error.

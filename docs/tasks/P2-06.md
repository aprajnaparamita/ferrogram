## Goal

everything unmapped lands in `Preserved` (ADR 0012), unknown parts stay in
the package. Inheritance is never flattened (ADR 0013).

## Interfaces

Implements:

```rust

```

Adds `crates/vsdx/src/xml/` (owned by this task, used by P2-07):

```rust
/// Parses one XML part into a preserved tree, enforcing
/// `max_xml_depth` and `max_attributes_per_element`.
pub fn parse_part(bytes: &[u8], limits: &Limits) -> Result<ferrogram_model::XmlNode, Error>;
/// Serializes a preserved tree to UTF-8 XML text (P2-07 uses it).
pub fn serialize_part(node: &ferrogram_model::XmlNode) -> Result<Vec<u8>, Error>;
```

Mapping rules (documented in the module docs):

- `pages.xml` + `page{N}.xml` -> `Document::pages` and the shape arena;
  `masters.xml` + `master{N}.xml` -> `Document::masters` and master shapes;
  `document.xml` -> stylesheet, document properties, root `Preserved`.
- Shape `Cell`/`Section`/`Row`/`Cell` elements map to `Sheet`; cell `U` is
  the `Unit`, `V` the cached value (canonical units, ADR 0011), `F` the
  formula string.
- Every unmapped attribute goes to the entity's `Preserved::attributes`;
  every unmapped child to `Preserved::children`, in order.
- Malformed-but-recoverable input degrades, never panics: a missing master
  part gives `Master::shape: None`. `CellValue::Error(raw)` is only for
  cached error values (`#VALUE!`). A numeric value that fails to parse for
  its declared unit is `Err(Error::InvalidPackage)` naming the part and the
  cell.
- `Document::kind` from the main part's content type (ADR 0016).

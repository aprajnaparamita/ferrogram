## Goal

Wire recalculation into the one edit seam: `AppCtx::push_edit` runs the
pass over the step's dirty cells (and again after `revert`), wraps the
step and a `RecalcEdit` value snapshot into one undo entry, and the
editing commands report their dirty cells. Resize stops calling
`scale_geometry`; `GUARD` protects its cell from indirect writes.

## Interfaces

You implement:

- `commands::recalc::{recalc_after_edit, RecalcReport}` (signatures
  committed; add `RecalcEdit` and `fill_missing` helpers in `recalc.rs`)
- `Edit::dirty_cells` for `CellEdit`, `StructuralEdit`, `GeometryEdit`
  (`builtins::edit`); the default stays `&[]`
- `AppCtx::push_edit`'s recalc extension (in `app.rs`)

Consumed by P6-08 (the fill-in pass entry point in `recalc.rs`), P6-09
(the panel edit commands), P6-10 (the exit-criterion test drives edits).

## Acceptance criteria

- [ ] One user action is one undo step including every recalculated cell;
      undo restores the previous values **by snapshot** (test that a
      recomputed cell's pre-edit value, including an unknown function's
      cached value, comes back unchanged).
- [ ] The ADR 0040 undo property holds for a resize with formulas (run,
      undo, compare documents; run, undo, redo, compare).
- [ ] Resize of a master instance recomputes geometry through `recalc`
      and never calls `scale_geometry` (assert in a test; the model
      function is untouched).
- [ ] A `GUARD`-ed cell survives an indirect write (move/resize) with one
      `Guarded` warning and its formula unchanged; a direct cell edit
      replaces it.
- [ ] A failing edit changes nothing and recalculates nothing (ADR 0039).
- [ ] `dirty_cells` covers every edit type that writes cells (a test per
      type).
- [ ] Connector re-routing skips a connector whose geometry rows carry
      formulas (ADR 0056's rule, one test).
- [ ] Hand-off gate green in the worktree (AGENTS.md section 7: `--quick`
      plus **coverage**; no fuzz step unless you change a fuzzed crate's
      public API; **wasm** if you touch any `Cargo.toml`).

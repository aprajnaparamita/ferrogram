## Goal

1. Test the uncovered branches of `connector.rs`, `insert.rs`,
   `shape.rs`, `edit.rs` and `view.rs` through the registry, the same
   way the existing tests in `crates/commands/tests/` dispatch commands.
   Error arms first: bad or missing arguments, unknown ids, no document,
   no page, a stale selection.
2. Assert behavior, not just reachability: the error names the problem,
   a failed command leaves the document and the undo stack unchanged,
   and undo restores the model exactly.
3. Leave margin: aim for **98.4%** or higher, so the next handler change
   does not drop the crate under the floor again.

## Result

### What changed

Added integration tests only (no file under `crates/commands/src/` was
touched):

- `crates/commands/tests/connector.rs`: argument validation for
  overflowed and wrong-kind connector/target/point ids, the
  no-active-page path, and proof that each error leaves the document
  unchanged.
- `crates/commands/tests/editing.rs`: non-text `edit.select` mode,
  delete without an active page, delete with a stale page, all-stale

  without an active page, clearing the entered group, panel commands
  without a document or with a stale anchor, and `shape.exit_group`
  without a document or with a stale group.

  connection point overflows, stale and missing active pages, argument
  names for every non-finite number, and out-of-range glue ids/rows.
- `crates/commands/tests/coverage_p5.rs` (new): page navigation without
  an active page, `view.zoom.fit` over unusable page-sheet cells and
  without/with a stale active page, a route error through
  `connector.reroute_all`, the "connectors were not re-routed" warning
  from an edit/delete/undo, glue revert after its page is gone, a stale
  connector record, and the public report helpers added by P5-09
  (`shape_count` with stale and repeated ids, `warning_line` error and
  theme substitutions, `sheet_text` stale ids, every `value_text` kind,
  `kind_text` for stencils and templates, and an unnamed page in

issues against handler code. No new dependencies.

### Remaining uncovered lines

`llvm-cov` reports these source lines with no executed region in the
workspace run. The summary's misses also include partially covered lines
whose uncovered part is a `?` error arm; those are covered wherever an
input can reach them.

Original five files:

- `builtins/connector.rs:421`, `468`, `557`: closing `?` of
  `GlueEdit::new` / `CellEdit::new` on otherwise successful paths. The
  constructors are called after the page and shape ids were validated;
  their error arms need a stale id between validation and the call,
  which no command input can produce in one dispatch.
- `builtins/connector.rs:661`: glued target vanishing between
  `drop_detached_targets` and the reference loop. The same pass drops
  those records first, so the lookup cannot be `None` here.
- `builtins/connector.rs:728`, `764`: closing braces mapped to the
  "page missing" arm of `drop_all_for` / `drop_detached_targets`;
  `reroute_after_edit` returns before calling either when the page is
  missing. The bodies are covered by the stale-connector and
  stale-target tests.
- `builtins/connector.rs:740`: `drop_detached_targets` with no page,
  unreachable for the same reason.
- `builtins/edit.rs:573`: no active session in
  `deleted_glue_warnings`; `run_delete` resolves the session through
  `selection_targets` immediately before.
- `builtins/edit.rs:616`: closing `?` of `StructuralEdit::removal` for
  an already on-page target; `selection_targets` guarantees the page.
- `builtins/edit.rs:648`: closing brace of the selection refresh when
  the session slot exists; the delete ran against that slot.
- `builtins/insert.rs:168`: the redundant finite check after
  `need_finite` already rejected non-finite sizes (defensive code).
- `builtins/insert.rs:419`-`421`: a catalog master without connection
  points. Every shipped catalog master has at least two, so no
  `insert.shape` input reaches the arm.
- `builtins/insert.rs:485`, `507`: non-finite source connection-point
  transforms. `insert.shape` writes only finite `Pin`/`LocPin` from a
  finite `x`/`y`; the master points are finite, so the transform stays
  finite.
- `builtins/insert.rs:574`: "the new shape vanished" between insertion
  and selection; both happen in the same dispatch with no concurrent
  mutation.
- `builtins/shape.rs:139`, `160`, `198`, `241`, `249`, `279`: closing
  `?` of `cell_edit` / `GeometryEdit::new` on the successful calls
  (move, resize, rotate). The error arms need a stale shape or session
  between the validated reads and the constructor; no command input
  reaches them, and the line table maps the closing paren to that arm.
- `builtins/view.rs:339`: `pages.get(index)` after the empty-page check
  and `rem_euclid(len)`; the index is always valid. An empty document is
  also disabled by `has_pages` (the existing test asserts `NotEnabled`).

P5-09 files (added to the scope by the master after the rebase):

- `builtins/arrange.rs:300`, `399`, `411`: the distribute loop's closing
  brace and the two successful `CellEdit::new` closings. The align and
  distribute tests execute the bodies; the uncovered mapping is the
  `?` error arm, which needs a stale shape between `target_frame` and
  the constructor.
- `builtins/clipboard.rs:142`: closing `?` of `paste_content` in
  `edit.duplicate`; the success path is covered, the error arm needs the
  document write to fail mid-paste.
- `builtins/clipboard.rs:347`: `None => (0.0, 0.0)` when a pointer paste
  has no root. `paste_content` returns "the clipboard holds no root
  shape" before this match, so the arm is unreachable.
- `builtins/file.rs:425`: `run_close` with `ctx.active` set but no
  session; `has_document` disables the command in that state.
- `builtins/file.rs:574`: `write_file` failing inside the export loop.
  Reaching it needs a host-dependent unwritable output path, so the
  suite does not assert it.
- `builtins/file.rs:681`, `721`, `753`: catch-all `_` arms of exhaustive
  enums (`DocumentKind`, `WarningKind`, `CellValue`); no value can reach
  them. `file.rs:777` is a `panic!` in the `file.rs` unit-test helper,
  not library code reachable from a command.
- `builtins/page.rs` has no zero-count source line in the workspace run;
  its remaining summary misses are partially covered `?` arms that need
  the session or page to disappear between `active_page` and the model

No line in these files is left for P5-09 or P5-17 as a handler change;

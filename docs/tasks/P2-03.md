## Goal

Implement the geometry types the model and the `.vsdx` mapper need now: unit
conversions to and from canonical units, point/size/rect arithmetic, angles
and affine transforms. No path/arc/NURBS/spline types (Phase 3).

## Interfaces

Implements the stubs already in `crates/geom`:

```rust
impl Unit {
    pub fn to_canonical(self, value: f64) -> Result<f64, Error>; // lengths -> inches,
                                                                 // angles -> degrees,
                                                                 // percent -> fraction
    pub fn from_canonical(self, value: f64) -> Result<f64, Error>;
}
```

Adds the pure operations the stubs deliberately left out (signatures fixed
here):

```rust
impl Point {
    pub fn add(self, other: Point) -> Point;
    pub fn sub(self, other: Point) -> Point;
    pub fn scale(self, k: f64) -> Point;
}
impl Rect {
    pub fn width(self) -> f64;
    pub fn height(self) -> f64;
    pub fn union(self, other: Rect) -> Rect;
    pub fn contains(self, p: Point) -> bool;
}
impl Angle {
    pub fn from_radians(radians: f64) -> Angle;
    pub fn radians(self) -> f64;
}
impl Transform {
    pub fn translate(t: Point) -> Transform;
    pub fn rotate(a: Angle) -> Transform;
    pub fn scale(sx: f64, sy: f64) -> Transform;
    pub fn apply(self, p: Point) -> Point;
    pub fn then(self, next: Transform) -> Transform; // `next ∘ self`
    pub fn invert(self) -> Result<Transform, Error>; // singular -> Err, never panics
}
```

`Unit::to_canonical`/`from_canonical` return `Err(Error::NotImplemented)` no
longer: a unit outside a category (e.g. degrees for a length cell) is
`Err(Error::WrongUnit)` — add that variant in `crates/geom/src/error.rs`.
Every conversion is exact where the factor is exact (points: 1/72 inch) and
documented otherwise (miles, ciceros).

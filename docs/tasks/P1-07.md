## Goal

Build a dev-only harness for libvisio's CLI tools (`vsd2raw`,
`vss2raw`, `vsd2xhtml`, `vss2xhtml`, `vsd2text`, `vss2text`) and a
small `cargo xtask oracle` task that wraps the build. The harness
is **optional for the gate**: a missing build does not fail the
gate; a test that uses the oracle is gated behind
`FERROGRAM_REQUIRE_ORACLE=1` (set in CI on Linux and macOS, not
Windows). See ADR 0010.

## Build script: `tools/libvisio-oracle/build.sh`

- Args: `build`, `clean`, `status`. Default: `status`.
- Resolves the build directory as
  `/Volumes/Dara/ferrogram/build/libvisio-oracle/` by default.
  Override with `--build-dir <path>` (CI sets this on Linux
  runners).
- `status`: prints `built` and exits 0 if all six binaries exist
  under `<build-dir>/bin/`. Prints `not built` and exits 0 if
  anything is missing. Exits non-zero only on a hard error (cannot
  read the directory).
- `build`:
  - If `status` is `built`, exit 0.
  - Run `git submodule update --init --depth 1
    tools/libvisio-oracle/libvisio` (or `git clone` if the host
    does not have submodules configured). The commit hash is
    pinned in `build.sh`; the same hash is in `NOTICE` and
    `docs/sources.md`.
  - `cd libvisio && ./autogen.sh && ./configure --prefix="$BUILD_DIR" --disable-werror`.
  - `make -j"$(nproc 2>/dev/null || sysctl -n hw.ncpu)"`
  - `make install` (which writes to `$BUILD_DIR/bin/`).
  - On any error, exit non-zero with the failing command's output.
- `clean`: `rm -rf "$BUILD_DIR/bin"`. Exit 0.
- A `--jobs N` flag overrides the parallelism (CI uses `-j 2`).
- The script is POSIX sh; no bash-isms. It must work on macOS,
  Linux, and the build containers used by CI.

The `tools/libvisio-oracle/libvisio/` submodule is added by:

```sh
git submodule add https://git.libreoffice.org/libvisio tools/libvisio-oracle/libvisio
git -C tools/libvisio-oracle/libvisio checkout c7c970775b750a4bf7fd1b4364d69bac9815bfcb
```

The `c7c970775b750a4bf7fd1b4364d69bac9815bfcb` commit is in `NOTICE`
and `docs/sources.md` (source 6).

## `xtask/src/oracle.rs`

A small module exposing the oracle to Rust tests. The public API:

```rust
/// The name of an oracle binary.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum OracleBinary {
    Vsd2Raw,
    Vss2Raw,
    Vsd2Xhtml,
    Vss2Xhtml,
    Vsd2Text,
    Vss2Text,
}

impl OracleBinary {
    pub fn file_name(self) -> &'static str;  // e.g. "vsd2raw"
}

#[derive(Debug, thiserror::Error)]
pub enum OracleError {
    #[error("libvisio oracle not built: {}. Run tools/libvisio-oracle/build.sh.", default_path())]
    NotBuilt { binary: OracleBinary },
    #[error("io error running {binary}: {source}")]
    Io { binary: OracleBinary, source: std::io::Error },
    #[error("{binary} exited with {status}:\n{stderr}")]
    NonZeroExit { binary: OracleBinary, status: i32, stderr: String },
}

/// Returns the absolute path to the binary, or `OracleError::NotBuilt`
/// when the oracle is not built.
pub fn binary_path(binary: OracleBinary) -> Result<std::path::PathBuf, OracleError>;

/// Runs the oracle binary with `args`, returns stdout.
pub fn run_capture(binary: OracleBinary, args: &[&str]) -> Result<String, OracleError>;
```

The default build dir is
`/Volumes/Dara/ferrogram/build/libvisio-oracle/`. Override with
`FERROGRAM_ORACLE_DIR=<path>` (used by CI on Linux).

`xtask/src/main.rs` adds an `oracle` task:

```
cargo xtask oracle status
cargo xtask oracle build [--build-dir <path>]
cargo xtask oracle clean
```

`status` calls `build.sh status`; the output line is
`oracle: built` or `oracle: not built`. CI uses this to skip oracle
tests on machines where the build is too heavy.

## Goal

Implement the layout API and the font stack, bundle the two fonts with
their licences, and make missing fonts and glyphs warn instead of fail.

## Interfaces

Implements (signatures fixed by P3-01):

```rust
pub fn layout(block: &Block<'_>, fonts: &FontStack) -> Result<Layout, Error>;

impl Font {
    pub fn from_bytes(bytes: Vec<u8>) -> Result<Font, Error>;
    pub fn outline(&self, glyph: GlyphId) -> Result<ferrogram_geom::Path, Error>;
}
```

`Font::outline` returns the glyph outline in **em units** (size 1);
backends scale by `size / 72` inches per point (ADR 0024). `skrifa` parses
and outlines fonts, `harfrust` shapes runs (kerning and default features),
`unicode-linebreak` gives break opportunities; the wrappers stay in
`crates/text/src/font.rs` so the crates can be swapped later.

Also provides (new, documented):

```rust
/// The bundled Carlito faces (for Calibri).
pub static CARLITO: &[FontSource];   // or one const per face; your choice
/// The bundled Selawik faces (for Segoe UI).
pub static SELAWIK: &[FontSource];
/// Builds the default stack: Carlito, then Selawik.
pub fn default_fonts() -> FontStack;
```

Consumers: `ferrogram-render` (P3-05 builds `TextNode`s, P3-06/P3-07 draw
glyph outlines).

## Acceptance criteria

- [ ] `layout` implemented: wrapping at the box width, `\n` hard breaks,
      alignment (left/center/right/justify by word spacing), line spacing
      multiples, space before/after, first-line and left indents, bullets,
      tab stops (with the 0.5-inch overflow rule), vertical alignment,
      margins and block rotation.
- [ ] Shaping uses `harfrust`; font parsing and outlines use `skrifa`; line
      break opportunities use `unicode-linebreak`.
- [ ] Missing family falls back down the stack with
      `Warning::MissingFont`; a missing glyph falls back and warns with
      `Warning::MissingGlyph`; layout never errors on either.
- [ ] Carlito and Selawik are committed under `crates/text/fonts/` with
      their OFL licence files, one `ATTRIBUTION.md` row per file (same
      commit) and `docs/sources.md`/`reference/SOURCES.md` rows (source
      URL, retrieval date, version, licence).
- [ ] Unit tests cover every layout feature and both warnings; numeric
      expectations are pinned (golden layout numbers, not images).
- [ ] `cargo xtask gate` green, including `cargo deny check` (OFL-1.1 is
      allowed) and the wasm build of `ferrogram-text`.
      `ferrogram-text` coverage meets its 75% threshold.

## Note from the master

Selawik may not ship italic faces (its releases list Light, Semilight,
Regular, Semibold and Bold). Bundle the faces that exist, check the licence
of the release you take, and do not synthesise font files. If italics are
missing, define the fallback (for example: an italic Segoe UI run uses
Selawik upright with a synthetic slant in the layout output, or falls back
to Carlito Italic), record it in an ADR 0024 amendment, and add a test.
Keep the total size of the bundled fonts in the Result.

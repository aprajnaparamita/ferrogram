## Goal

The pointer tool works end to end: select and marquee, move, resize and
rotate with handles, snapping on, overlays drawn over the cached raster,
fast enough to drag a 1000-shape page.

## Interfaces

Implement the stubs exactly as signed (`ToolMachine::handle`,
`pointer::handle`, `handles::{handle_at, handles_for, selection_bounds}`,
`snap::{Snapper::snap_move, snap_point}`). Dispatch rules (ADR 0042):
`ToolMachine::handle` is read-only over `&AppCtx` and returns
`ToolEffect { intents, overlay }`; the shell executes the intents. The
canvas cache key becomes `(SessionId, changes, page, raster scale)` and
drops the per-frame document comparison (ADR 0040 rule 3).

Your `ToolMachine::handle` routes `ToolEvent`s to the other tool modules
(`draw`, `stencil`, `text`, `connector`) by `ToolMachine::tool`; those
modules are owned by P5-06..P5-08 and stay `Err(UiError::NotImplemented)`
until they land — dispatch to them and propagate their errors unchanged.

Consumers: P5-06..P5-08 add tool modules and may add at most these lines
of yours: `canvas.rs` — the tool-picker wiring lines they name in their
Results; `shell.rs` — none.

## Acceptance criteria

- [ ] Select, shift-toggle, marquee (replace/add per ADR 0041) and
      clear-on-page-switch work, with the panels showing the anchor
      shape.
- [ ] Move, resize (8 handles) and rotate through one drag each,
      dispatching `shape.move`/`shape.resize`/`shape.rotate`, one undo
      step per drag.
- [ ] Snapping (grid, alignment, connection points; Alt disables) per
      ADR 0043, with snap guides on the overlay.
- [ ] The canvas re-rasterizes only when `changes`, the page or the zoom
      rule fires; a drag re-rasterizes nothing (asserted in a test with a
      counting seam or a cache-statistic).
- [ ] Keyboard focus moves change the active shortcut scopes (a
      `egui_kittest` test that focuses the canvas with Tab and dispatches
      a `page`-scoped shortcut).
- [ ] Drag frame budget of ADR 0042 (8 ms for 1000 shapes) is measured
      in P5-11; you include the timing harness hook it needs or note it
      under Open issues.
- [ ] `egui_kittest` tests cover: click-select, marquee, one move drag,
      one resize, one rotate, Alt-disable snap.
- [ ] No `unwrap`/`expect`/`panic!` in non-test code; tool events in any
      order never error the app (worst case: no-op).

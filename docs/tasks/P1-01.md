### Dataset shapes (for P1-02's extractor design)

#### 1. Fluent UI control identifiers (`reference/fluent-ui-ids/`)

- **Files:** 4 Visio `.xlsx` files for Office 2013, Office 2016, Office 2019, and Microsoft 365 Current Channel (plus Monthly Enterprise Channel and Semi-Annual Enterprise Channel).
- **File format:** Office Open XML SpreadsheetML (`.xlsx`). One worksheet per file. Single header row plus data rows.
- **Row counts (Visio sheets):** 903, 889, 978, 1161 (header + data). Other applications have analogous `.xlsx` files.
- **Columns (9 used + 1 unused):**
  - `Control Name` (string, e.g. `FileSave`, `ConnectorTool`).
  - `Control Type` (string, vocabulary of 19: `button`, `toggleButton`, `group`, `gallery`, `contextMenu`, `tab`, `menu`, `splitButton`, `checkBox`, `button (dialogBoxLauncher)`, `dropDown`, `task`, `comboBox`, `labelControl`, `tabSet`, `taskFormGroup`, `category`, `control`, plus 3 "None (...)" placeholders).
  - `Tab Set` (string).
  - `Tab` (string, e.g. `TabHome`, `Quick Access Toolbar`).
  - `Group/Context Menu Name` (string).
  - `Parent Control` (string).
  - `Secondary Parent Control` (string, often empty).
  - `Tertiary Parent Control` (string, often empty).
  - `Policy ID` (integer).
  - `Column1` (always empty).
- **Relationships:** the parent columns form a 3-level ancestry chain (so a control's full command bar position can be reconstructed); `Tab Set` and `Tab` together form the command bar location independent of the parent-control chain.
- **Caveat:** `Control Name` strings are not the same as `visUICmdXxx` constants in source 2 — they are command bar XML IDs. Some appear in both (e.g. `ConnectorTool`); many don't (`FileSave` is a built-in).

### Open issues for the master agent / follow-ups

- The Visio file format is documented primarily in a Microsoft-published XSD that is embedded inside a Microsoft Learn markdown page (`schema-mapvisio-xml.md`), not as a standalone `.xsd` file. The XSD text carries a Microsoft copyright notice; we will extract element/type names and structure, never commit the verbatim XSD. P1-02's extractor design should account for parsing the schema from this embedded source.
- The `support.microsoft.com/en-us/office/keyboard-shortcuts-for-visio-...` URL now returns a redirect stub. We are using a Wayback Machine archive. P1-02 should record this in the extractor design.
- The VisUICmds and Fluent UI Control Name strings are **different identifier spaces**. P1-02 must decide which is the canonical command id; based on the task ("VisUICmds: UI command ID constants, to be used in conjunction with the CmdNum property"), VisUICmds is the canonical set, and Fluent UI IDs are only the command bar location labels. Cross-referencing both will produce a `CommandId` -> placement path map.

## Work items

### Code fixes (from the review)

1. **Default namespace (review finding 1, major).** Resolve unprefixed
   element names against the in-scope default namespace in
   `package/xml.rs`. Attribute names stay in no namespace. Update every
   hand-built expected tree that relied on `uri: None` for Visio names, so
   the parser and `emit.rs` agree. Add parse and `diff` tests:
   `<Cell xmlns="urn:x"/>` equals `<p:Cell xmlns:p="urn:x"/>` and differs
   from `<Cell/>`. The corpus round-trip must stay green.
2. **Blank text (finding 2).** In `write/patch.rs`, `remove_children` drops
   whitespace-only text only when it actually removed elements. Test: an
   element whose only content is blank text keeps it.
3. **Shared helpers (finding 3).** Move the copies of `main_part`,
   `is_main_content_type`, `rel_type_local`, `resolve_target`,
   `text_content` and the colour parsing into one module each, used by both
   the reader and the writer. No behavior change.
4. **Cache lock (finding 4).** In `model/src/lookup.rs`, recover a poisoned
   lock with `into_inner()` and insert-or-reuse in one critical section, so
   no value is leaked per call.
5. **Relationship children (finding 5).** Keep child elements of a
   `Relationship` in its `Preserved` and write them back. Test it.
6. **Doc wording (finding 6).** Make the `raw.rs` docs and ADR 0012 say what
   the code does: a number literal with an optional unit suffix compares
   numerically; suffixes must match; units never convert; text compares
   exactly. Date the ADR change "Amended 2026-10-14, P2-14".

### Value kinds on write (P2-10 open issue 1)

7. When the writer emits a cell value the model built (not one read from a
   file with its `U`), it writes the `U` the reader needs to get the same
   kind back: `U="BOOL"` for `Bool`, `U="STR"` for a `Str` that would
   otherwise read as a number or colour. `List` stays out of scope (the
   formula engine owns it); say so in the module docs. Remove the exclusion
   from the P2-10 `from_model` property generator for `Bool` and `Str`.

### Coverage gaps (from the coverage audit)

8. Major 1: tests for the reader's sheet-level preservation fallbacks
   (`read/sheet.rs`): an unmapped `Cell`, `Row` and `Section` child, and an
   unknown cell attribute, each kept and written back.
9. Major 2: write into `Package::new()` and into a package without
   `[Content_Types].xml`; both re-read to the same model.
10. Major 3: one test per error `write_document` can return.
11. Minors 1 to 5: the streaming size cap, unknown elements in
    `[Content_Types].xml`, inference for an unknown extension, odd
    relationship part names, a newline in cell text and in an attribute
    (round-trip), and a master parent cycle in the lookup.
12. Minor 6: mark the `map_or_else(|| emit::empty(...))` miss arms as
    defensive with one comment at the helper, or restructure so they are
    not needed.
13. Minor 8: a test that lists which `Unit` values the writer spells as `?`,
    and a decision in the code comment (error or keep).
14. Minor 10: tests for `U` removal when the model takes over a unit, and
    for wrapping loose `Connect` elements in a new `Connects`.

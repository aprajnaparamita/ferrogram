## Goal

Prove the phase: run the cross-check over every corpus formula and report
the agreement rate with cached values (ADR 0059), and pin the exit
criterion in a test — resizing a master-based corpus shape recomputes its
geometry correctly for supported functions.

## Interfaces

No new public interfaces: both files are integration tests over the
committed API. The cross-check prints the ADR 0059 block on stdout
(`-- --nocapture` shows it) and asserts every counted cell agrees within
tolerance; any accepted divergence goes into ADR 0059's exclusion list
(you may append to that ADR's "Documented exclusions" section — one line
each, with the reason).

## Acceptance criteria

- [ ] The cross-check runs over all 15 corpus files and prints the
      per-file table, the skip counts per reason and the total agreement
      rate (ADR 0059's format).
- [ ] Every counted cell agrees within the ADR 0059 tolerance; a
      disagreement fails the test with the cell address, formula, cached
      and evaluated value in the message.
- [ ] `FERROGRAM_REQUIRE_CORPUS=1` makes the harness mandatory; without
      the corpus it skips with a reason.
- [ ] `exit_resize.rs` reads `blue-box.vsdx` and `qs-box.vsdx`, resizes a
      master instance through the model mutation API, runs recalc, and
      asserts the geometry rows equal hand-computed expectations (no
      cached value from the file used).
- [ ] The Result reports the numbers the phase report needs: the
      agreement rate, the counted/skipped split and the resize case.
- [ ] Hand-off gate green in the worktree (AGENTS.md section 7: `--quick`
      plus **coverage** and **fuzz** if you change the shapesheet public
      API, **wasm** if you touch any `Cargo.toml`).

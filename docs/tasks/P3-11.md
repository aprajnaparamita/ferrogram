### Tests added

- **Property tests (ADR 0027 section 6), the three the phase owed:**
  - `crates/model/tests/geometry_properties.rs` (new): random `Geometry`
    rows type without ever panicking — random `T` spellings, cell kinds
    (`Bool`, `List`, `Error` included), formula text, duplicate/negative
    `IX`, `Del` rows, and the same through a two-rung master chain.
  - `crates/text/tests/layout_properties.rs` (new): random runs in a
    random box lay out without panicking and every output value is
    well-formed (finite positions/sizes, run and font indices in range);
    random invalid blocks error without panicking; extreme-but-finite
    inputs never panic. New dev-dependency: `proptest` on
    `larrygram-text`.
  - `crates/render/tests/scene_properties.rs` (extended): the two scene
    properties now assert the outputs **parse** — every PNG decodes
    (`Pixmap::decode_png`) and every SVG is balanced XML — instead of
    discarding them.
- **Malformed/adversarial decoders:** `parse_nurbs_data_edge_spellings`
  and `parse_polyline_data_edge_spellings` (model: spacing, stray
  parentheses, trailing commas, quoted junk, infinity semantics,
  separator set, no bare-list fallback for `POLYLINE(...)`),
  `marker_ix_trims_whitespace_and_respects_the_bounds` and
  `fields_nested_in_fields_stack_their_markers` (vsdx `Text`),
  `a_slot_falls_through_an_unparsable_colour_to_the_next_child`,
  `an_unparsable_alpha_falls_back_to_opaque` and
  `color_entry_indices_and_colours_say_what_they_accept` (vsdx theme).
- **Boundaries:** `crates/render/tests/boundaries.rs` (new): empty and
  single-shape scenes through build and both backends with the output
  parsed, the zero-size page fallback, a huge page capped with
  `TooLarge`, a huge scale (PNG capped, SVG writes — see Open issues),
  and text overflow through the builder.
- **CLI arguments at their boundaries:** `page_numbers_stay_in_their_bounds`,
  `scale_values_stay_in_their_bounds`,
  `format_and_background_values_are_exact`,
  `non_utf8_arguments_are_usage_errors` (parse), and
  `a_huge_scale_is_exit_three_not_a_panic`,
  `a_huge_page_is_exit_three_not_a_panic` (exec, end to end).

### Bug found and fixed

`Line::width` could be a tiny negative number: `finalize` computed it as
`pen - x_start - shift`, which cancels for a zero-advance line. Now the
sum of the advances (`crates/text/src/layout.rs`). Regression test
`a_zero_advance_line_has_a_non_negative_width` pins the minimal input the
property found and was verified to fail against the pre-fix code. All
pre-existing tests pass unmodified.

## Goal

Implement `DocumentResolver`: resolve every reference form of ADR 0054
through the rungs of ADR 0013, evaluate an inherited formula in the
target sheet's context, prefer the local `Inh` snapshot for values, and
turn a missing reference into `#REF!` with one warning. Close the P3-15
"master-sized geometry on resized instances" rendering gap by the
`CellReader` policy change in `crates/model/src/values.rs`.

## Result

### What changed

- **`crates/shapesheet/src/resolve.rs`** — `DocumentResolver` now
  resolves every reference form of the ADR 0054 table through the rungs
  of ADR 0013 over the model:

  | Form | Resolution |
  |---|---|
  | `Width` | the model's lookup (`Document::resolve` / `resolve_page_cell`), the local entry's spelling found case-insensitively first |
  | `Star!Angle`, `Executive.2!Height` | named shape on the target's page; `Name.N` matches Visio `ID` N (and the name) |
  | `Sheet.8!FillForegnd` | the shape with `ID` 8 on the target's page |
  | `Masters[Gear]!Shaft!Geometry1.X1` | master by name, its named sub-shape, then the cell |
  | `Pages[Page-3]!Sheet.4!BeginX` | page by name, then its shape |
  | `Styles!Manager!LineColor` | stylesheet row's sheet |
  | `ThePage!User.Vanishing_Point` | the page sheet |
  | `TheDoc!PreviewQuality` | `Document::properties` (see open issues) |
  | `'1-D'!LineColor`, `'A''B'!...` | quoted names, `''` unescaped |
  | `Char.Size`, `Char.Font[3]`, `Scratch.A5`, `Geometry1.X2`, `Prop.Cost`, `User.Name` | the row-shape rules against the section: a column of the section's rows (trailing digits or `[n]` = row index) first, a named row of a named-row section second, with the section instance from the section's trailing digits |

  Row cells walk local then master rungs (the sub-shape and position
  rules of ADR 0013, no style rung for a section cell) and end at the
  table's hard default. A name that resolves to nothing is `#REF!` with
  exactly one warning and never an error. `EvalContext::cell_value`
  evaluates the defining formula in the target sheet's context (the
  resize-recompute rule) with a recursion bound (`MAX_EVAL_DEPTH` 32);
  `set_cell` applies a basic `SETF` write.
- **`crates/shapesheet/tests/resolve.rs`** (new) — one test per row of
  the ADR 0054 table over a small in-memory document, the `Inh`
  snapshot rule with its provenance pin, the inherited-formula rule
  (a master's `Width*0.5` row binds `Width` to the instance's sheet),
  `#REF!` + one warning for a missing cell, row and sheet, case-
  insensitive lookup and the `SETF` contracts.
- **`crates/model/src/values.rs`** — the one policy change (ADR 0054
  amendment, ADR 0057): `CellReader` returns the sheet's own cached
  value for a cell that has one, `Inh` snapshots included, and no longer
  warns about them. The fallback chain (defining rung's cached value,
  documented default, hard default) is unchanged and provenance still
  comes from `Document::resolve`, which is unchanged (its own tests
  still pin `Master(..)`). New tests pin the rule at `CellValue` level.
- **`crates/model/src/geometry.rs`** — deviation, 3 lines: the
  geometry row reader resolves its row cells itself (`RowContext`), and
  a row snapshot needs the row identity that `CellReader::number_from`
  cannot see; `RowContext::resolve` now applies the same rule through
  `values::prefer_row`. This is the case that closes P3-15 (an instance
  whose geometry rows carry `F='Inh'` and its own-size snapshots). Two
  geometry tests that pinned the old behaviour were flipped
  (`a_section_level_inh_cell_keeps_its_snapshot`, and the partial-row
  values of `sparse_instance_rows_merge_with_the_master_rows`).
- **`crates/vsdx/tests/read_mapping.rs`** — deviation, one test:
  `sparse_geometry_rows_merge_with_the_master_rows` pinned master-sized
  geometry on a resized instance, i.e. the P3-15 gap this task closes.
  It now asserts the instance's own snapshots (6.988 in wide against the
  master's 1.575 in) for the rows the instance carries and the master's
  rung for the rest.

### Deviations and notes

- **`Document::resolve` is unchanged.** The ADR 0013 amendment words
  the value/formula split as a lookup change; per this task's ownership
  rule the split lives in the consumers (`DocumentResolver`,
  `CellReader`) and the lookup keeps its contract and its tests. The
  observable values are the same. See open issues if the master wants
  the split inside `lookup.rs`.
- **Warning name.** The acceptance criteria say one `MissingReference`
  warning; the evaluator's committed warning type spells it
  `EvalWarningKind::UnsupportedReference(text)` (`eval.rs` is P6-04's).
  The resolver emits that one warning per missing name; P6-06's recalc
  maps it to `RecalcWarningKind::MissingReference`.
- **`Value::from_cached` (P6-03) is the value mapping.** The resolver
  hands it the cell's own recorded unit for every cell it names, so the
  value reads back in the unit the file wrote; a value from a style rung
  or a table default passes `Unitsless` (the lookup's `Resolved` carries
  no unit). The shapesheet tests compare through `from_cached`, so they
  pin the mapping's result exactly (P6-03 merged under the rebase).
- **`cell_value` falls back to the cached value** while
  `eval_formula` (P6-04) is a stub, and when a stored formula does not
  parse (the ADR 0053 unknown-function pattern).
- **Missing-row semantics.** Section instance 0 and row 0 are the
  conceptual first section/first row of the row shape (a formula may
  read `Char.Size` on a sheet with no `Character` section and gets the
  default); a named row or a higher index that exists on no rung is
  `#REF!`.
- **P2-02 table gap.** `Scratch`'s `A`..`F` cells are not in
  `ui-spec/shapesheet.toml`, so the row-shape rule also accepts a column
  the file itself writes in those rows. No table edit (ADR 0060 defers
  the gap until a corpus reference needs it).
- **SETF writes** land as literals (formula cleared) on an existing
  cell; a target nothing names is refused with
  `Error::Conversion("SETF target ...")` (no better variant exists in
  `error.rs`).

### Open issues

1. **Warning naming:** `EvalWarningKind::UnsupportedReference` is the
   `MissingReference` of ADR 0054 and the criteria. Consider renaming it
   (or aliasing) in `eval.rs` when P6-04 lands; P6-06 should map it to
   `RecalcWarningKind::MissingReference` in recalc warnings.
2. **`TheDoc`:** the model has no document sheet, so
   `TheDoc!<cell>` resolves against `Document::properties`. A real
   document sheet (or a documented properties mapping) would close the
   gap; `crates/model/src/document.rs` is not mine.
3. **`Error` variants:** a refused `SETF` target and a broken context
   would deserve their own variants (`error.rs` is P6-02's).
4. **Optional lookup-side split:** if the master prefers ADR 0013's
   wording literally ("the lookup now splits formula from value"),
   moving the snapshot preference into `lookup.rs` is a small follow-up
   that flips its two `Inh` value tests; every reader already sees the
   amended values through this task's consumer-side split.

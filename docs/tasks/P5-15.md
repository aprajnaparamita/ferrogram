### Remaining uncovered lines in `mutate.rs`, and why

`cargo llvm-cov show` (the per-line view) marks five source lines
uncovered; none is reachable by any input:

- **778** `}` of `if let Some(entity) = self.pages.get_mut(page.index)`
  in `detach_shape`: `page_of` found that page earlier in the same call
  and nothing can remove it in between.
- **1505, 1513** `)?;` of the `FlipX`/`FlipY` writes in
  `ungroup_shape`: `checked_number` only rejects a non-finite `Number`
  and these writes carry a `Bool`; the child ids were validated above.
  The `PinX`/`PinY`/`Angle` error arms of the same loop are covered.
- **1679** `return Err(Error::TooManyShapes)` in `check_room`: needs
  `Document::shapes.len() >= 1 << 24`. A test would have to build 16
  million arena shapes (many GB of memory); the cap is a safety bound.
- **1820** `return Err(Error::BadCell("non-finite master size"))` in
  `master_size`: `CellReader`'s policy substitutes finite values for
  missing and non-finite cells (ADR 0021), so `frame.size` is never
  non-finite.

`cargo llvm-cov report`/`xtask coverage` count lines per region, so

## Goal

Close the value pipeline end to end: the fill-in pass after a read (so
the five blank corpus files render), and the writer's typed `V`/`U`
spelling (so a value we write reads back the same, P2-14). The writer
still never recalculates and `read(write(read(write(d))))` still equals
`read(write(d))` (ADR 0048).

## Interfaces

You implement:

- `crates/vsdx` value spelling: `U` for every `CellValue` kind (drop the
  unit of a `Bool`/`Str`, spell `U="BOOL"`/`U="STR"`), and the matching
  read side
- the fill-in call in `builtins::file.rs` after a successful read
- optionally, the removal of the two P5-10 preservation artefacts
  (`Cell::preserved` kind spelling, the `<Rel>` child), each with a
  round-trip test

Nothing new is exported; the vsdx public API stays as it is unless a
Result note says otherwise.

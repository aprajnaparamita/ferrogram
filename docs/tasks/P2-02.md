## Goal

Implement `cargo xtask codegen [--check]` exactly as ADR 0015 specifies:
deterministic TOML-to-Rust generation into `crates/model/src/generated/shapesheet.rs`,
a `--check` mode that fails on drift, and a fast gate step that runs the check.

## Interfaces

Consumes `ui-spec/shapesheet.toml`. Produces, inside `pub mod generated`
(ADR 0015):

```rust
pub struct SectionDef {
    pub name: &'static str,
    pub section_index: i32,
    pub kind: &'static str,
    pub default_unit: &'static str,
}
pub struct RowDef { pub name: &'static str, pub row_index: i32, pub section: &'static str }
pub struct CellDef {
    pub name: &'static str,
    pub section: &'static str,
    pub cell_index: i32,
    pub kind: &'static str,
    pub default_unit: &'static str,
    pub default_value: Option<&'static str>,
}
pub static SECTIONS: &[SectionDef];
pub static ROWS: &[RowDef];
pub static CELLS: &[CellDef];
pub static CELL_INDICES: &[(&str, i32)];
pub static SECTION_INDICES: &[(&str, i32)];
pub static ROW_INDICES: &[(&str, i32)];
pub fn cell(section: &str, cell: &str) -> Option<&'static CellDef>;
pub fn section(name: &str) -> Option<&'static SectionDef>;
```

### What changed

- `xtask/src/codegen.rs` (new): `cargo xtask codegen [--check]`.
  Parses `ui-spec/shapesheet.toml` (via `toml`, no new dependency),
  sorts everything (sections by name, cells by name within a section,
  rows and index enumerations by name) and deterministically renders
  two committed files:
  - `crates/model/src/generated/shapesheet.rs`: `SectionDef`, `RowDef`,
    `CellDef`, `SECTIONS` (47), `ROWS` (51), `CELLS` (420),
    `CELL_INDICES` / `SECTION_INDICES` / `ROW_INDICES`, and the
    `cell()` / `section()` lookups, plus small generated self-tests.
    First line is the ADR 0015 header; every public item is
    documented (`cargo doc` clean).
  - `crates/model/src/generated/mod.rs`: `pub mod shapesheet;` with a
    `pub use shapesheet::*;` re-export, same header.
- `--check` regenerates into a scratch directory and compares
  byte-for-byte (CRLF tolerated, like `extract --check`), and fails
  naming each stale/missing file and the fix command
  (`run \`cargo xtask codegen\` and commit the result`). Both paths
  have tests in `xtask` (fresh/stale/missing/CRLF).
- `xtask/src/main.rs`: the `codegen` task arm (`Task::Codegen`) and
  usage text.
- `xtask/src/gate.rs`: new `codegen` step, first in `STEPS`, running
  the check; `--quick` does not skip it and `gate --quick` reports it.
- `crates/model/src/lib.rs`: the single `pub mod generated;` line.

Re-running `cargo xtask codegen` is byte-identical (tested). The
generated Rust is rustfmt-clean, so `fmt` and `codegen --check` agree.

### Deviations from the task interface (source data has gaps)

The committed table records no value for some entries, so three
"plain" fields are `Option` (the closest correct version of the
interface):

- `CellDef.cell_index: Option<i32>` — 10 of 420 cells (e.g.
  `Actions!FlyoutChild`) have no `cell_index` in the TOML.
- `SectionDef.section_index: Option<i32>` — `Layer Membership` has no
  `section_index`.
- `RowDef.section: Option<&'static str>` — 8 of 51 rows (e.g.
  `visRowNone`, `visRowInval`) have no owning `section`.

Other notes: the gate step calls `codegen::run` in-process (the same
code path as `cargo xtask codegen --check`) instead of spawning
`cargo xtask` again; the generated file carries generated self-tests
so `larrygram-model` keeps its coverage threshold.

### Open issues

- ADR 0015's interface sketch says `cell_index: i32`,
  `section_index: i32` and `RowDef.section: &'static str`; with the
  real table these must be `Option`s (see deviations). The ADR should
  be updated by whoever owns it, and P2-04 should code against the
  `Option` fields.
- The renderer emits rustfmt-styled code by construction. If a future
  rustfmt version reformats the generated file, `fmt` and
  `codegen --check` will disagree until the renderer is adjusted.
- `ui-spec/shapesheet.toml` also carries an `enumerations.vis_unit_codes`
  table; ADR 0015 lists only the three index enumerations, so it is
  not generated. Say the word if `model` wants it.

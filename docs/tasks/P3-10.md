## Interfaces

Provides (integration tests and helpers; keep helpers in
`tests/common/` of the crate that owns them):

- `tests/golden.rs`: the comparison metric of ADR 0027 (same dimensions;
  per-channel delta <= 2 of 255; at most 0.5% of pixels above it), with
  unit tests on synthetic images; `FERROGRAM_UPDATE_GOLDEN=1` regenerates
  the goldens and prints which changed.
- `tests/corpus_render.rs`: every `corpus/vsdx/*.vsdx`, every page, both
  backends; skip without the corpus, mandatory with
  `FERROGRAM_REQUIRE_CORPUS=1`.
- `tests/oracle_render.rs`: structural comparison against `vsd2xhtml`
  (page counts, per-page shape and path counts, bounding box within 0.05
  inches) behind `FERROGRAM_LIBVISIO_ORACLE`, mandatory with
  `FERROGRAM_REQUIRE_ORACLE=1`; skips record the reason.
- `tests/scene_properties.rs`: proptest over the scene builder and the row
  mapping (bounded random models never panic).
- `fuzz/fuzz_targets/render_document.rs`: bytes -> `read_document` ->
  `build_scene` -> `render_png`/`render_svg`, no panic; edition 2024; seed
  corpus committed.
- Fixture builder extensions: `build(Feature(..))` constructors for one
  file per KICKOFF rendering feature (every geometry row type absolute and
  relative, fills, lines, shadows, text, master inheritance, theme colors
  and fonts, layers, page size, background pages).

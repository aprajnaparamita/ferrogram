## Goal

Build the scene graph of a page: every shape as a filled/stroked path with
the right transform, paint, stroke, shadow and text, warnings for bad
values, no panics.

## Interfaces

Implements (signatures fixed by P3-01):

```rust
pub fn build_scene(doc: &Document, page: PageId,
                   options: &BuildOptions) -> Result<Scene, Error>;
```

Consumes: `Document::shape_geometry`, `CellReader`, `Document::page_layers`
and `Document::shape_layers` (P3-02); `Curve::to_cubics` and `Path`
(P3-03); `text::layout` (P3-04); `VisualStyles` templates (P3-08). May add
private helpers in `build.rs` (row-to-path mapping, transform composition,
paint resolution) and documented public items only if the backends need
them (they should not: the scene is the contract).

## Acceptance criteria

- [ ] `build_scene` is implemented and never panics on any corpus file;
      bad values produce `Scene::warnings` entries per ADR 0021.
- [ ] Transform composition matches ADR 0020 (pin, local pin, angle,
      flips, group nesting) with tests against hand-computed matrices.
- [ ] Every geometry row type maps to the right path — one test per
      `GeometryRow` variant, absolute and relative (this is half of the
      phase exit criterion: "every geometry row type has tests"). The
      mapping uses `Curve::to_cubics` with `0.25 / scale` default
      tolerance at 96 ppi (ADR 0022).
- [ ] Master inheritance is visible in scenes: an instance without local
      geometry renders the master's geometry (test with a corpus file).
- [ ] Fills (solid, linear and radial gradients from the cached gradient
      cells), strokes (width, dash from `LinePattern` templates, caps,
      joins, `Rounding`, line ends from `BeginArrow`/`EndArrow` with
      `*ArrowSize` scaling), shadows (from the shadow cells and templates),
      text blocks (runs resolved through `TextContent` and the
      `Character`/`Paragraph`/`Tabs` rows), layer visibility and
      background pages all appear in the scene (test each).
- [ ] Page size comes from the page sheet (`PageWidth`/`PageHeight`);
      `Scene::width`/`height` are inches.
- [ ] `cargo xtask gate` green; `ferrogram-render` coverage meets its 75%
      threshold.

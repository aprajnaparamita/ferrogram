## Interfaces

Implements (signatures fixed by P3-01):

```rust
impl VisualStyles {
    pub fn load() -> Result<VisualStyles, Error>;
    pub fn line_pattern(&self, index: u32) -> Option<LinePatternTemplate>;
    pub fn line_end(&self, index: u32) -> Option<LineEndTemplate>;
    pub fn fill_pattern(&self, index: u32) -> Option<PatternTemplate>;
    pub fn shadow(&self, index: u32) -> Option<ShadowTemplate>;
}
```

`load` parses `include_str!("../data/visual-styles.yaml")` with
`serde-saphyr` (already a dependency of `crates/render`); unknown indices
return `None` and the caller substitutes the no-op style with a warning
(ADR 0021). The data file format is the one in ADR 0023; extend it with
extra optional fields only if a template needs them, and note the change
in the Result.

Consumers: `ferrogram-render`'s scene builder (P3-05) scales templates by
the shape's cells (dash by `LinePattern` and line width, arrowheads by
`BeginArrowSize`/`EndArrowSize`, tiles by spacing, shadows by the shadow
cells).

## Goal

Implement `cargo xtask codegen [--check]` exactly as ADR 0015 specifies:
deterministic TOML-to-Rust generation into `crates/model/src/generated/shapesheet.rs`,
a `--check` mode that fails on drift, and a fast gate step that runs the check.

## Interfaces

Consumes `ui-spec/shapesheet.toml`. Produces, inside `pub mod generated`
(ADR 0015):

```rust
pub struct SectionDef {
    pub name: &'static str,
    pub section_index: i32,
    pub kind: &'static str,
    pub default_unit: &'static str,
}
pub struct RowDef { pub name: &'static str, pub row_index: i32, pub section: &'static str }
pub struct CellDef {
    pub name: &'static str,
    pub section: &'static str,
    pub cell_index: i32,
    pub kind: &'static str,
    pub default_unit: &'static str,
    pub default_value: Option<&'static str>,
}
pub static SECTIONS: &[SectionDef];
pub static ROWS: &[RowDef];
pub static CELLS: &[CellDef];
pub static CELL_INDICES: &[(&str, i32)];
pub static SECTION_INDICES: &[(&str, i32)];
pub static ROW_INDICES: &[(&str, i32)];
pub fn cell(section: &str, cell: &str) -> Option<&'static CellDef>;
pub fn section(name: &str) -> Option<&'static SectionDef>;
```

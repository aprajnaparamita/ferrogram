## Goal

Connectors glue to shapes, route straight or with one right-angle elbow,
and re-route when their shapes move — ours, not Visio's (ADR 0045).

## Interfaces

Implement `geom::routing::route` (signature fixed by P5-01),
`tools/connector::handle`, and `builtins/connector.rs` `TABLE` with:

- `connector.glue_begin` / `connector.glue_end` — args `connector`
  (Visio id), `target` (Visio id), optional `point` (the connection row
  `IX`; absent = outline glue); one undoable edit each.
- `connector.unglue` — args `connector`, `end` (`"begin"`/`"end"`).
- `connector.reroute_all` — no args; recomputes every glued connector's
  path on the active page (idempotent, not undoable).
- `connector.style` — arg `style` (`"straight"`/`"right_angle"`).

Also export from `builtins/connector.rs`:
`pub(crate) fn reroute_after_edit(ctx: &mut AppCtx, page: PageId)
-> Result<usize, CommandError>` — the hook the editing commands call
after a move/resize/rotate/delete/undo/redo (P5-04 wires the calls; if
its task already landed without them, add the two call lines to
`builtins/shape.rs` and `builtins/edit.rs` and note it in the Result).

The connector tool drags out a connector from a connection point or
shape to another, previewing the routed path on the overlay (ADR 0042)
and committing `insert.shape` (the connector master instance, P5-06's
command) plus the glue records.

## Acceptance criteria

- [ ] `route` implements both styles with the ADR 0045 deterministic
      elbow rule; degenerate endpoints return the two points (tested).
- [ ] Glue to a connection point and to an outline works; a new glue
      replaces the old; unglue removes the record (tested headlessly).
- [ ] Moving, resizing, rotating or deleting a glued shape re-routes the
      affected connectors (one edit, one re-route pass), including after
      undo and redo (tested through the registry).
- [ ] A glue whose target is detached drops with one warning line.
- [ ] The exit-flowchart path (P5-10) can build a 5-connector flow from
      these commands; no command needs a GUI.
- [ ] No `unwrap`/`expect`/`panic!`/`indexing_slicing` in new code
      (geom is a parser-class crate for this lint); bounded work per
      connector.
- [ ] Hand-off gate green in the worktree (AGENTS.md section 7:
      `cargo xtask gate --quick`; add **wasm**/**fuzz** only if you touch

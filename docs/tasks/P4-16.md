## Goal

1. **Errors reach the user (review major 2).** Every `Err` that
   `Shell::dispatch` gets back for an intent goes to `note_error` (one
   line, ADR 0021), not only `NotEnabled`. A cancelled dialog stays
   quiet. Both apps keep working as before.
2. **No dialog for programmatic sources (review major 3).**
   `apply_outcome` handles a payload (save dialog or download) only for
   `source.is_interactive()`; for other sources the outcome goes back
   to the caller untouched. Test both.
3. **Options through the registry (review major 4, ADR 0032
   amendment).** `show_options` no longer mutates `Settings`: it returns
   the `Intent`s for what the user changed (`view.ui_layout.*`,
   `view.toggle_grid`, `view.rulers`, `view.units` with its `units`
   argument), and the shell dispatches them. Remove the shell
   intercepts for `app.quit` and `app.office.center.options`: the shell
   handles `UiRequest::ShowOptions` and `UiRequest::Quit` from the
   registry instead.
4. **Review minors.**
   - 9: drop `UiError::NotImplemented` (no producer left). Leave the
     context menus parked; note it.
   - 10: remove `Shell::show(&Context)` (the panic footgun); tests and
     callers use `show_in`.
   - 11: a page whose raster fails is not retried every frame:
     remember the failed cache key and retry only when the key
     changes. Report the error once.
5. **Shortcut mismatch (P4-10).** When a chord mismatches a half-typed
   sequence and fires the held-back shorter completion, the
   mismatching chord is then tried as the start of a new sequence
   instead of being dropped. Update the test that pins the old
   behavior and the ADR 0036 wording is already compatible (say if
   not).
6. **Coverage gaps (P4-12 majors 1–4).**
   - the `NeedsInput` retry, pending and no-dialog arms in
     `shell.rs`;
   - every arm of the shortcut `key_token` table (a table-driven test
     that maps each egui key to its token and back);
   - the canvas raster failure path and its `UiError::Render` mapping;
   - the native picker bodies: if they cannot run headless, move the
     rfd calls behind the thinnest seam you can test, and say what is
     left untested.
7. Add `proptest` to `crates/ui` dev-dependencies and turn at least the
   settings-slot round trip (P4-10, `crates/ui/tests/settings_slot.rs`)
   into a `proptest` property.

## Goal

1. **Icon table.** `cargo xtask codegen` writes
   `crates/ui/src/icons/table.rs`, an `include_bytes!` table from icon
   name to SVG bytes for every name in `icons.yaml`. `--check` fails
   when the table and the map disagree.
2. **Icon cache.**
   - Rasterise with `resvg` (latest 0.48.x, MIT OR Apache-2.0).
   - Cache key: (icon, size px, tint colour, pixels-per-point).
   - Replace `currentColor` before parsing.
   - The cache is bounded (LRU, 1,024 entries).
3. **Public API.**
   - `icons::icon_atom(key, size, &Theme, enabled) -> Atom` and
     `icons::draw(ui, rect, key, ...)`.
   - Fall back to the placeholder for an unknown key or a rasterisation
     error, and log once per key.
   - Disabled icons are drawn at 40% alpha.
4. **Image loaders.** Add `egui_extras` with the `svg` and `image`
   features (ADR 0067) and register its loaders, so the wizard and the
   About window can load `about_screen.svg`, `panel-layout.svg`,
   `classic-layout.svg` and `larry.png`. `cargo deny` must stay green
   (P7-01 checked the closure licences in a scratch workspace).
5. **Wasm build**: icons and images render in `larrygram-web`.

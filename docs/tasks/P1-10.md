## Goal

Audit coverage as described in your role file.
- Run `cargo xtask coverage`. Use `cargo llvm-cov --workspace --all-features --html` (output under your `CARGO_TARGET_DIR`) for line detail.
- Table per crate: lines, covered, percent, threshold, ratchet (`coverage.toml`), delta from the ratchet. Include `xtask` and every crate with zero lines.
- List uncovered critical paths with `path:line` ranges: loader error branches, file I/O errors, extractor failure paths, the corpus fetcher's network and checksum errors, the oracle wrapper.
- Recommend the new `[ratchet]` values for the end of Phase 1. Do not edit `coverage.toml`; the master updates it.
- Note any crate where the measured number is misleading (for example `vsd-binary`, whose only code is under `tests/`, which `llvm-cov` excludes).

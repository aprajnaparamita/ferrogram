## Goal

Close every finding below with a fix and a regression test (or, where
the review allows it, a documented rule).

### Major

1. **One write path for `SETF` (review F1).** A `SETF` inside a
   referenced cell's formula, evaluated inline during a read, must not
   write through `DocumentResolver::set_cell`. Record the write and let
   the pass apply it through `Evaluation::writes` and `apply_write`, so
   it gets a `CellUpdate`, dirties its dependents and is inside the undo
   snapshot. A read-only context for nested evaluations is acceptable
   only if the ADR 0056 text then says nested `SETF`s are dropped, with
   a warning. Turn the "F1 reproduces" path into a test, including one
   through `RecalcEdit` showing undo restores the target.
2. **One column-versus-row rule (review F2).** Give `shapesheet` one
   helper that answers "what does this name mean against this section"
   and use it from both `resolve.rs` (`column_known`) and
   `graph.rs` (`is_column`, `resolve_ref_address`). Merge the twin name
   splitters (`split_row_name`/`split_section_name`/`canonical_section`
   against `split_row_suffix`/`split_section_number`/`spell_section`).
   Turn the "F2 reproduces" path into a test: an edit re-evaluates the
   dependent formula.

### Major findings

1. **One write path for `SETF` (review F1).** `DocumentResolver::set_cell`
   **records** the write (`RecordedWrite`); only the recalc pass applies
   writes (`apply_write`, through the model's mutation API), so a write —
   the formula's own or one inside a referenced cell's formula that a
   read re-evaluated inline — gets its `CellUpdate`, dirties its
   dependents and sits inside the `RecalcEdit` snapshot. The old
   `RecordingContext` is gone and nothing writes the document during
   evaluation. Tests: `tests/recalc_engine.rs::a_nested_setf_lands_through_the_pass`
   (the nested write lands through the pass with its `CellUpdate`),
   `commands/src/recalc.rs::a_nested_setf_write_is_inside_the_undo_snapshot`
   (through `RecalcEdit`: undo restores the target), and
   `tests/recalc_engine.rs::a_standing_back_evaluation_drops_its_writes_and_names_the_cell`
   (the "F1 reproduces" path: the write is dropped per item 3, so
   nothing lands outside the pass). The crosscheck's bare-resolver hole
   closes with the same change: a counted `SETF` can no longer mutate
   the document under test.
2. **One column-versus-row rule (review F2).** New
   `crates/shapesheet/src/names.rs` owns the name splitters
   (`split_row_name`, `split_section_name`, `canonical_section`, the
   section/row/slot lookups) and the one rule
   (`row_kind`/`column_known`); `resolve.rs` (`column_known`,
   `find_section_in`, `write_target`) and `graph.rs`
   (`resolve_ref_address`, `resolve_write_address`) both use it. The
   graph's twin splitters (`is_column`, `split_row_suffix`,
   `split_section_number`, `spell_section`, `named_row`, `canonical_row`,
   `base_name`) are deleted, and `resolve_ref_address` now walks the
   master rungs behind the sheet (reads inherit; writes stay local, the
   new `resolve_write_address`). Tests: `tests/graph.rs::a_reference_resolved_through_a_master_builds_its_edge`
   and the "F2 reproduces" path `tests/recalc_engine.rs::an_edit_of_a_master_cell_reevaluates_the_dependent_formula`
   (an edit of the master's `Size` recomputes the instance's `PinX`).

### Minor findings

3. **F3 (rule recorded in ADR 0056).** A standing-back evaluation
   (`UnknownFunction`, `Syntax`) keeps its cached value **and drops the
   `SETF` writes it recorded** (the pass applies writes only when it
   does not keep the cache). Test: `a_standing_back_evaluation_drops_its_writes_and_names_the_cell`.
4. **F4.** Hand-written `PartialEq` for `Expr` comparing `kind` only
   (`ast.rs`); `without_spans` (parser.rs) and `strip` (tests/parser.rs)
   deleted. The parse-print-parse properties now compare directly.
5. **F5 (ADR 0051).** The omitted-argument decision is recorded: the
   EBNF has no empty-argument production; one is added when a function
   in the evaluated set needs it.
6. **F7.** Nested evaluations count against the budget:
   `Evaluation::evaluations` reports its own plus every nested
   evaluation (a counter on the resolver) and `recalc_with` adds them.
   Test: `tests/recalc_engine.rs::the_budget_counts_nested_evaluations`.
   ADR 0056 records the rule.
7. **F8.** `warning_line` prints one line per kind
   (`WrongArgumentCount`, `SetfRefused`, `Coercion`, `NonFinite`,
   `Syntax`); `commands/src/recalc.rs::warning_lines_name_the_problem`
   tests each (with one case per argument-span spelling).
8. **F13.** `run_pass` returns `PassRun { report, before }`: the
   snapshots already taken come back **with** the error, and `wrap`/
   `apply` keep them. Tests:
   `a_pass_that_fails_mid_way_keeps_its_snapshots_for_undo` (a
   test-only failing engine) and
   `a_redo_whose_pass_fails_keeps_the_step_and_warns`.
9. **F16.** `TracedWarning` carries the referenced cell whose formula
   was being evaluated; the pass reports the warning against that cell.
   Test: `a_standing_back_evaluation_drops_its_writes_and_names_the_cell`

10. **F17.** The stranded sentence in `eval.rs`'s module docs is

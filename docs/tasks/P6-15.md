## Goal

1. **The style rung uses the effective style link.** When an instance
   has no `LineStyle`/`FillStyle`/`TextStyle` of its own, the lookup uses
   the link of its master shape (the same master shape the formula rung
   uses), then the master's own chain. A link the instance sets wins.
   Keep the cycle guard and the "never a panic" rule.
2. **The three files render.** Remove `dwg`, `fdo86664` and `testfile5`
   from `KNOWN_BLANK` in `open_corpus.rs`, and check that each one
   rasterises non-blank.
3. **A rule for files with nothing to draw.** `tab-short-prefix` has no
   size, geometry or text cells and no formulas, and `recursion-cycle`
   has no page contents. Keep them marked, but give each marker a reason
   that states this ("nothing to draw by construction"), so a reader of
   the harness knows they are not a bug.
4. **Amend the ADRs.** ADR 0013: the style rung follows the master's
   links when the instance has none. ADR 0057: correct the first
   consequence. The blank files were a style-inheritance gap, not missing
   cached values, and the fill-in pass is a no-op on the current corpus.

### Deviations

1. **No new public API.** `Document::effective_style_link` is a private
   method (a public one would need a public `StyleKind`; the task allows
   an accessor only "if the rule needs" one). The render crate and
   `CellReader` read through `Document::resolve`, so nothing outside
   `lookup.rs` needs the link itself.
2. **"The same master shape the formula rung uses" is read as the whole
   master chain, in rung order.** A master that is itself an instance
   with no link of its own continues the search at its own master (goal
   1's "then the master's own chain"). The first link found wins.
3. **A dangling link the instance sets wins over the master's valid
   link** ("a link the instance sets wins", taken literally): the style
   rung then ends where it starts, as for any dangling link. Pinned by
   `a_dangling_link_of_the_instance_wins_over_the_masters`; if Visio's
   black-box behaviour turns out to fall through to the master's link
   instead, that test is the switch.
4. `resolve_row_cell` keeps its "no style rung" rule (ADR 0019 decision
   5); the effective-link rule only touches the style rung of
   `Document::resolve`, which is where the blank corpus files resolved
   `FillPattern`/`LinePattern`.

## Goal

Fill the function table with the decided set (ADR 0053) and implement the
evaluator: operator evaluation with Visio coercion, the functions of the
set with their error values, `GUARD` (a no-op value-wise in evaluation;
the protection rule is P6-07's), basic `SETF` through `EvalContext`, and
the unknown-function rule (the cell keeps its cached value and one
warning is recorded).

## Interfaces

You implement (signatures committed by P6-01):

- `functions::{FunctionDef, FunctionKind, FUNCTIONS, lookup_function,
  is_supported}`
- `eval::{EvalContext, EvalWarning, EvalWarningKind, eval, eval_formula}`

Consumed by P6-05 (the resolver implements `EvalContext`), P6-06 (recalc

the contract: `cell_value`, `set_cell`, `warn`. Changing the trait is a
Result note, not a silent edit.

## Acceptance criteria

- [ ] `FUNCTIONS` holds every name of the ADR 0053 evaluated set with
      correct arity bounds; a test asserts the names match the reference's
      spelling and that `is_supported` agrees with the table.
- [ ] One test per function family (arithmetic on mixed units, comparison
      coercions, `IF` evaluates only the taken branch, `MIN`/`MAX` of
      unit values, `INT`/`ROUND`/`CEILING`/`FLOOR`/`MOD` edge cases,
      trig, `DEG`/`RAD`, `RGB`, `INDEX`/`LOOKUP` bounds, `NA`,
      `STRSAME`, `IFERROR`).
- [ ] `GUARD(x)` evaluates to `x`; `SETF(target, value)` writes through
      `EvalContext::set_cell` and evaluates to `value`; a `SETF` target
      the context refuses is `#REF!` with a warning.
- [ ] An unknown function keeps the caller's cached value path and records
      one `UnknownFunction` warning per formula (test with `THEMEVAL`).
- [ ] Wrong argument count is `#VALUE!` plus one warning, never a panic.
- [ ] Division by zero is `#DIV/0!`, a non-finite result is `#NUM!`.
- [ ] Hand-off gate green in the worktree (AGENTS.md section 7: `--quick`
      plus **coverage**, **fuzz** if you change the shapesheet public API
      (the `parse` target exists after P6-02), **wasm** if you touch any
      `Cargo.toml`).

## Master notes

- P6-03 merged (`coerce` and values). `coerce::coerce` now returns
  `Coerced { value, defaulted }`, not `Result<Value, Error>`: it never
  fails, and `defaulted` tells the evaluator to record a coercion
  warning. `Coerced` is exported from the crate root. Adapt your calls
  when you rebase.

- P6-05 merged. The resolver reports a missing cell, row or sheet as
  `EvalWarningKind::UnsupportedReference`, which is ADR 0054's
  `MissingReference`. Rename the variant to `MissingReference` in
  `eval.rs` (or document the mapping) and keep the resolver's use
  compiling when you rebase.

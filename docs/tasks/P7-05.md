## Goal

1. **Apply a theme.** `theme::apply(ctx, &Theme)` sets egui `Style` and
   `Visuals` from the tokens, as mapped in `docs/ui/themes.md`, and
   registers Selawik (Regular, Light, Semibold) from `crates/text/fonts`
   as the proportional UI font.
2. **Token lookups.** `theme::color(&Theme, token)` and
   `theme::metric(...)` return a default for a missing token and warn
   once per token (never panic).
3. **Canvas colours.** The canvas reads `canvas.background`,
   `page.background`, `page.border`, `page.shadow` and the ruler
   colours.
4. **Switching.** Switching layout re-applies its theme on the next
   frame.

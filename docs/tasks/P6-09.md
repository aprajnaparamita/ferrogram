## Goal

Show typed values in the Shape Data and Size & Position panels and accept
typed input with unit suffixes, converting through the engine's unit
table and `Settings::units`. Formula cells are read-only and say so.

## Interfaces

No new public interfaces: the panels read through `CellReader`
(`ferrogram-model`) and the engine's `Value` (`ferrogram-shapesheet`),
and write through registry commands only (`ferrogram-commands`). Any
helper you need lives as a private function in `panels.rs`.

## Acceptance criteria

- [ ] Shape Data shows each `Prop` row's value typed: a number with its
      unit in `Settings::units`, a boolean, a colour, a string (a test
      per kind through `egui_kittest`).
- [ ] Size & Position shows the evaluated `PinX`/`PinY`/`Width`/`Height`/
      `Angle` and marks formula cells read-only.
- [ ] Entering `2.5 cm` into an inch field stores the converted value;
      `37%`, `45 deg` and `5 1/2` parse like the grammar (ADR 0051);
      a bad entry is refused with one status line and no model change.
- [ ] A formula cell refuses edits (one status line), and the test proves
      the document is unchanged.
- [ ] Every accepted edit dispatches one registry command and is one undo
      step (the panel never touches the model directly).
- [ ] Hand-off gate green in the worktree (AGENTS.md section 7: `--quick`
      plus **coverage**; **wasm** if you touch `crates/ui/Cargo.toml`;
      fuzz only if you change a fuzzed crate's public API (you do not)).

## Goal

Implement the value type's operations: the unit table (parse, spelling,
family, canonical conversion, the `geom` bridge), the coercion rule of

`Value::to_cached`/`from_cached` mapping that closes P2-14, and the
non-finite rule (a non-finite result is `#NUM!`, never a stored `inf`).

## Result

**Done 2026-10-21, branch `agent/P6-03`, 4 implementation commits plus
this one.** All
of `crates/shapesheet/src/{units,value,coerce}.rs` and the new
`crates/shapesheet/tests/values.rs`; no other file touched.

- **`units.rs`**: the full unit table of `about-units-of-measure.md`
  (source 19). `parse_unit` matches the universal *and* localized
  spellings case-insensitively (table-driven, `eq_ignore_ascii_case`, no
  allocation); the empty spelling is `Unitsless`. `spelling()` prints the
  universal one and round-trips through `parse_unit` for every unit.
  `family()` follows the ADR 0052 table (the compound spellings are
  Length, `°` is Angle). `to_canonical`/`from_canonical` use one factor
  per unit (inches, radians, fraction, seconds): exact for the exact
  factors (`72 pt = 1 in`, `1 deg = pi/180 rad`, `1 ft = 12 in`) and
  round-trip within `1e-12` for every unit (seeded property loop).
  `to_geom`/`from_geom` bridge the shared set and are strict elsewhere
  (see deviations). Nautical miles convert at 1 852 m (exact), a `date`
  serial counts days (`86 400 s/day`), ciceros/didots follow the didot
  point of `larrygram_geom` (0.376 mm).
- **`value.rs`**: `Value::to_cached`/`from_cached` close P2-14. A number
  converts to canonical and records the unit spelling (`U=` source); a
  unit the model does not carry records the family's canonical unit
  (inches/radians/percent), so the value survives even when the spelling
  does not. A non-numeric kind drops the unit on write (the P2-14 fix,
  with a test that reads it back). A list caches its `;`-joined raw
  string and parses back entry-wise (error spelling, `TRUE`/`FALSE`,
  `#RGB`/`#RRGGBB`, number, else string; the empty raw is the empty
  list; a nested list flattens). A non-finite magnitude is `#NUM!` in
  both directions, never a stored `inf`. New public helper
  `ErrorCode::from_text` maps a cached `#...` text back.
- **`coerce.rs`**: the one rule of `about-operators.md`. Documented
  conversions convert silently: a numeric string to a number, a number
  to a string (its magnitude: `2 * 5 & " cents"` is `"10 cents"`), a
  number to a boolean (`0` is `FALSE`), a boolean to a number (`1`/`0`,
  the `0`/`1` the files write, ADR 0021), and every kind to a string
  through its own spelling. Everything else falls back to the typed
  default (`0`, `""`, `FALSE`, black, the empty list) and flags it on
  `Coerced::defaulted`, so the caller records one `Coercion` warning
  (`5 * "sheep"` is `0`). An error value coerces to itself in every
  kind; a non-finite number is `#NUM!`. Coercion never fails and never
  panics. The `as_*` readers are strict typed views: `Err` when coercion
  would have to default.
- **`tests/values.rs`**: every spelling of the source parses (acceptance
  1), spelling round-trips (2), exact factors and the `1e-12` round-trip
  property (3), the coercion rule (4), the cached round-trip property per
  value kind and the P2-14 unit drop with a read-back test (5), the
  non-finite rule both directions (6), and the area spellings rejected as
  `Error::Syntax { kind: InvalidUnit }` (7). The property loops are
  seeded xorshift generators in the test file (see deviations).

**Deviations (interfaces):**

- `coerce` returns `Coerced { value: Value, defaulted: bool }`, not
  `Result<Value, Error>` (P6-01's stub): coercion never fails (ADR 0052)
  and the acceptance requires a `Coercion` warning, which needs a channel
  back to the caller. `Coerced` lives in `coerce.rs` and is **not
  exported** (`lib.rs` is not this task's file): request one line,
  `pub use coerce::Coerced;`. Until then P6-04 can still call `coerce`
  and read the fields by inference; its unit tests use the type.
- `to_geom`/`from_geom` return `Err(Error::Conversion)` for units the
  other side lacks (the stub docs said "or `None`"). `to_cached` does not
  fail on those: it records the family's canonical unit.
- `Unit::spelling(Unitsless)` is `Ok("")` and `parse_unit("")` is
  `Unitsless`, so spelling and parsing round-trip for every unit.
- No `proptest` dependency: `crates/shapesheet/Cargo.toml` is not this
  task's file ("Nothing else"), so the ADR 0060 property tests are
  seeded deterministic loops covering the same claims (256 rounds per
  kind, 64 magnitudes per unit). If the master prefers `proptest`, it is
  a dev-dependency plus a test rewrite in files this task owns.

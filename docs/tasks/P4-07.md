## Goal

Both panels render honest read-only data in Phase 4: document and page
data with no selection, formatted in the user's display units, with the
`Row` seam ready for Phase 5 editing.

## Interfaces

```rust
// crates/ui/src/panels.rs (stubs filled in)
pub struct PanelRow { pub label: String, pub value: String, pub edit: Option<(CommandId, Args)> }
pub fn PanelRow::read_only(label, value) -> PanelRow;
pub fn shape_data_rows(&AppCtx) -> Result<Vec<PanelRow>, UiError>;
pub fn size_position_rows(&AppCtx) -> Result<Vec<PanelRow>, UiError>;
pub fn show_shape_data(&mut Ui, &AppCtx) -> Result<(), UiError>;
pub fn show_size_position(&mut Ui, &AppCtx) -> Result<(), UiError>;
```

Content (ADR 0035): with no selection, `shape_data_rows` lists the
document's `Property` rows (name, value) and the active page's name;
`size_position_rows` lists the active page's width and height in
`Settings::units` and its name. `edit` stays `None` (Phase 5 fills it).
Missing or non-finite values render "—" and record one warning on the
`AppCtx` the caller passes (take `&AppCtx`; if recording a warning needs
`&mut`, return the warning text in `UiError::Io`? No: return
`Result<Vec<PanelRow>, UiError>` and put the warning string in a
`PanelRow` value; document your choice). Both `show_*` functions render
the rows as a two-column `egui::Grid`.

## Acceptance criteria

- [ ] `shape_data_rows` and `size_position_rows` return the documented
      rows for a document with one page (unit tests).
- [ ] Units: a 8.5 x 11 in page reads "8.5 in"/"11 in" in inches and
      "215.9 mm"/"279.4 mm" in millimeters.
- [ ] Missing values render "—", never a panic.
- [ ] Both panels render in an `egui::Context` test; `edit` is `None` on
      every row.

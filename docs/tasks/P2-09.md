## Goal

Build the harness that proves the Phase 2 exit criterion and the other
KICKOFF tests: corpus round-trips with semantic equivalence, malformed input
without panics, an oracle comparison, schema validation of written files,
and a fuzz target for the package reader.

## Interfaces

Consumes (all exist by the time this task starts):

```rust
ferrogram_vsdx::{read_document, write_document, Limits, Package};
ferrogram_model::diff(a: &XmlNode, b: &XmlNode) -> Result<Vec<XmlDifference>, Error>;
crates/vsdx/tests/common::{Fixture, Malformed, build};
```

Provides:

- `tests/roundtrip.rs`: for each corpus `.vsdx` — read, write, re-read,
  re-write; assert `diff` empty per XML part, equal part lists/content
  types/relationships, byte-equal binary parts, byte-identical second write
  (ADR 0012 exit rules). Skips with a message when `corpus/vsdx/` is
  missing; `FERROGRAM_REQUIRE_CORPUS=1` makes that a failure.
- `tests/malformed.rs`: every `Malformed` fixture through `read_document`,
  assert `Err` and no panic; one test per `Limits` cap.
- `tests/oracle.rs`: behind `FERROGRAM_LIBVISIO_ORACLE` (ADR 0010 helper,
  copy-paste `oracle_dir()` with its unit test). Compares page/master/shape
  counts and key cell values (`PinX`, `PinY`, `Width`, `Height`) against
  `vsd2raw` output where the oracle supports the format; otherwise the test
  prints what it skips. `FERROGRAM_REQUIRE_ORACLE=1` makes a missing oracle
  a failure. No libvisio code in the test.
- `tests/schema.rs`: extracts the XSD from the local `reference/` markdown
  into a temp file, runs `xmllint --schema` on each regenerated part of a
  round-tripped corpus file. Skips with a message when `reference/` or
  `xmllint` is missing; `FERROGRAM_REQUIRE_SCHEMA=1` makes that a failure.
  Records the XSD's licence from the docs repository's `LICENSE` at the
  pinned commit in `docs/sources.md` and states whether the XSD may ever be
  committed (default: no).
- `crates/vsdx/fuzz/fuzz_targets/read_package.rs`: `read_document` on raw
  bytes with default `Limits`, then (if it reads) `write_document` and a
  re-read; assert no panic. Edition 2024. Seeds: the hand-authored minimal
  and malformed fixtures.

## Goal

Move, resize, rotate, delete and select through the registry, each as one
undoable edit, with the ADR 0040 change counter and a safe undo runner.

## Interfaces

Implement, exactly as signed:

- `AppCtx::push_edit(&mut self, session: SessionId, edit: Box<dyn Edit>)
  -> Result<(), CommandError>` (the only push path; drops + warns while
  undo recording is suspended), and the suspension flag.
- `CompositeEdit::apply`/`revert` (forward/backward over `edits`).
- `builtins/edit.rs` `TABLE`: `edit.delete`, `edit.select_all`,
  `edit.deselect`; `builtins/shape.rs` `TABLE`: `shape.move`, `shape.resize`,
  `shape.rotate`, `shape.set.width`, `shape.set.height`, `shape.set.pin`,
  `shape.set.angle`, `shape.enter_group`, `shape.exit_group`.
  Argument names are contract: `shape.move` takes `dx`, `dy`; `shape.resize`
  takes `width`, `height`; `shape.rotate` takes `angle` (radians);
  `shape.set.pin` takes `x`, `y`; `shape.set.angle` takes `angle`;
  `edit.delete`/`edit.select_all`/`edit.deselect` take nothing.
- Extractor additions (one commit): the Phase 5 command ids
  `edit.{delete,select_all,deselect,copy,cut,paste,duplicate}`,
